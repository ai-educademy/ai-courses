## まず: どのような種類の AI を学びたいですか?

「AI を学習する」ということは、目的によって意味が大きく異なります。本題に入る前に、次のどれが自分に最も当てはまるかを判断してください。

**パス A — AI ユーザー / パワー ユーザー**
プロンプトエンジニアリング、AI API による構築、ワークフローの自動化など、仕事やビジネスに AI ツールを効果的に使用したいと考えています。モデルをトレーニングする必要はありません。
*スケジュール: 高度に熟練するまでに 4 ～ 8 週間かかります。*

**パス B — AI プラクティショナー / ML エンジニア**
機械学習モデルを構築、トレーニング、デプロイしたいと考えています。データを操作し、ML コードを作成し、実際の問題を解決します。
*スケジュール: 強固な基礎の場合は 6 ～ 18 か月。*

**パス C — AI 研究者**
あなたは、論文の出版、新しいアーキテクチャの発明、基礎的な作業など、AI ができることの限界を押し広げたいと考えています。
*タイムライン: 通常は修士号または博士号が必要です。 3 ～ 6 年以上。*

このガイドを読んでいるほとんどの人は、パス A またはパス B を選択しています。このガイドでは両方をカバーしており、各段階で明確にラベルが付けられています。

## 前提条件 (スキップしないでください)

### プログラミング: Python は交渉不可能です (パス B の場合)

Python は AI と機械学習の言語です。 Python を知らない場合は、ここから始めてください。専門家である必要はありません。コードの読み書きに十分慣れている必要があります。

**学ぶべきこと:**
- 変数、データ型、リスト、辞書
- ループ (`for`、`while`) および条件分岐 (`if/else`)
- 関数とモジュール
- ファイルI/O
- 基本的なオブジェクト指向プログラミング

**無料リソース:**
- [Python.org の公式チュートリアル](https://docs.python.org/3/tutorial/)]
- [Python で退屈なことを自動化する](https://automatetheboringstuff.com/) — 無料オンライン、実用的、優れた
- YouTube の freeCodeCamp の Python コース

**推定時間**: 継続的に続ければ 4 ～ 6 週間 (1 日あたり 1 ～ 2 時間)

### 数学: 実際にいくら必要ですか?

ここで人々は不必要にパニックを起こします。正直な答えは次のとおりです。

**AI ツールを使用する場合 (パス A)**: 数学は必要ありません。真剣に。

**ML モデルを構築する場合 (パス B)**: 次の実用的な知識が必要です。

- **確率と統計**: 分布、平均/分散、ベイズの定理 - 不確実性の処理方法

定理を証明できる必要は**ありません**。直感と方程式を読む能力が必要です。

## ステージ 2: コア機械学習 (パス B — 8 ～ 12 週間)

ここからが実際の仕組みに入ります。この順序で基礎を学習してください。

＃＃＃２ａ． NumPy と Pandas を使用したデータ処理

モデルを構築する前に、データを処理する必要があります。 NumPy と Pandas は、数値計算とデータ操作のための基本的な Python ライブラリです。

```python
import pandas as pd

# Load a dataset
df = pd.read_csv('housing_data.csv')

# Explore it
print(df.head())
print(df.describe())

# Handle missing values
df = df.dropna()

# Feature selection
X = df[['bedrooms', 'bathrooms', 'sqft']]
y = df['price']
```

**リソース**: [Kaggle の無料 Pandas マイクロコース](https://www.kaggle.com/learn/pandas) — 4 時間、実践

＃＃＃２ｂ．古典的な ML のための Scikit-Learn

Scikit-Learn は、従来の機械学習に頼りになる Python ライブラリです。これには、一貫したクリーンな API を備えた数十のアルゴリズムの実装が含まれています。

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, predictions):.2f}")
```

線形回帰、ロジスティック回帰、デシジョン ツリー、ランダム フォレスト、K-means クラスタリング、および SVM を実行します。それぞれをいつ使用するかを理解してください。

**リソース**: [Scikit-Learn の公式チュートリアル](https://scikit-learn.org/stable/tutorial/) + [Kaggle の ML マイクロコース](https://www.kaggle.com/learn)]

＃＃＃２ｃ．初めての実際のプロジェクト

## ステージ 3: ディープラーニング (パス B — 8 ～ 12 週間)

これで、ニューラル ネットワークに飛び込む準備が整いました。

＃＃＃３ａ． PyTorch または TensorFlow?

これらは 2 つの主要な深層学習フレームワークです。 2026 年の正直な推奨事項: **PyTorch から始める**。これはより Python 的で、研究でより広く使用されており、デバッグが簡単です。 TensorFlow/Keras は依然として本番環境で広く使用されていますが、その勢いは PyTorch にあります。

```python
import torch
import torch.nn as nn

# Define a simple neural network
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        return self.layers(x)

model = SimpleNet()
```

＃＃＃３ｂ．マスターすべき深層学習の重要な概念

- **フォワードパスとバックプロパゲーション** — モデルの学習方法
- **活性化関数** — ReLU、シグモイド、ソフトマックス
- **損失関数** — クロスエントロピー、MSE
- **オプティマイザー** — SGD、アダム
- **正規化** — ドロップアウト、バッチ正規化
- **畳み込みニューラル ネットワーク (CNN)** — 画像用
- **リカレント ニューラル ネットワーク (RNN)** — シーケンス用
- **Transformer アーキテクチャ** — 最新の LLM の基盤

**リソース:**
- [fast.ai 実践的なディープラーニング](https://course.fast.ai/) — トップダウン、実践的
- [Andrej Karpathy のニューラル ネットワーク: Zero to Hero](https://karpathy.ai/zero-to-hero.html) — GPT をゼロから構築します

**マイルストーン**: ニューラル ネットワークを最初から構築してトレーニングします (事前に構築されたモデルを呼び出すだけではありません)。

## ステージ 4: LLM の使用 (両方のパス — 4 ～ 6 週間)

2026 年には、どのような道を歩むにしても、大規模な言語モデルを扱う方法を理解することが不可欠です。

### パス A の場合 (LLM を使用):
- プロンプト エンジニアリングを徹底的に学びます — ゼロショット、少数ショット、思考の連鎖
- RAG (検索拡張生成) を理解する - LLM と独自のデータを組み合わせる
- OpenAI API、Anthropic API、またはオープンソース モデルを使用してシンプルなアプリケーションを構築する

### パス B (LLM を使用した構築) の場合:
- Transformer アーキテクチャを深く理解する (注意メカニズム、位置エンコーディング)
- ハグフェイストランスフォーマーで微調整を学びましょう
- パラメータ効率の高い微調整 (LoRA、QLoRA) を理解する
- オープンソース モデルの実験 (Llama、Mistral、Phi)

```python
from transformers import pipeline

# Using a pre-trained model in 3 lines
summariser = pipeline("summarization", model="facebook/bart-large-cnn")
result = summariser("Your long text here...", max_length=130)
print(result[0]['summary_text'])
```

## 避けるべきよくある間違い

**チュートリアル地獄** — 何も構築せずに次から次へとチュートリアルを見続けます。各チュートリアルの後、学んだことをすぐにプロジェクトに適用します。

**始める前にすべてを理解しようとする** — コードに触れる前に数学をマスターする必要はありません。直感は行動から生まれます。

**一人で学ぶ** — コミュニティを見つけます。 AI Discord サーバー、Kaggle コンテスト、または構造化された学習プログラムに参加してください。

**基礎をスキップする** — 勾配降下法を理解せずにいきなり LLM の微調整に飛びつくと、後になって大きな問題が生じることになります。

**新しいものを追い求める** — AI の状況は毎週変化します。新しいモデルのリリースを追う前に、ゆっくりと変化する基本をマスターしてください。
