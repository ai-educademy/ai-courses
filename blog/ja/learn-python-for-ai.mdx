## 1. 変数とデータ型

Python では、値を変数に保存します。型宣言は必要ありません。

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**これが AI にとって重要な理由**: モデルのハイパーパラメーター、精度スコア、構成値は変数として保存されます。 `learning_rate = 0.001` や `epochs = 50` のようなものが常に表示されます。

---

## 2. リスト

リストは、順序付けられた項目のコレクションです。 1 つの変数に複数の値を格納できます。

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**これが AI にとって重要な理由**: トレーニング履歴、ラベルのリスト、データのバッチ — すべてはリスト (または同様に機能する NumPy 配列) に保存されます。

## 3. 辞書

辞書にはキーと値のペアが格納されます。ラベルの付いた箱のようなものだと考えてください。

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**これが AI にとって重要な理由**: モデルの構成、トレーニング引数、および結果は、ほとんどの場合辞書として表されます。 AI コードに `config = {...}` が表示されると、これが起こっていることになります。

## 4. ループ

ループを使用すると、コレクション内の各アイテムに対してアクションを繰り返すことができます。

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**これが AI にとって重要な理由**: トレーニング ループは、複数のエポックのデータを反復処理します。データ前処理ループは、データセット内の各行をクリーンアップします。ほぼすべてのトレーニング スクリプトで `for epoch in range(epochs):` が表示されます。

## 5. 機能

関数は再利用可能なコードのブロックです。これらを一度定義すると、何度も呼び出すことができます。

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

関数にはパラメータのデフォルト値を設定できます。

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**これが AI にとって重要な理由**: すべての ML ライブラリは関数で構成されています。 `model.fit()`、`model.predict()`、`train_test_split()` — これらはすべて関数呼び出しです。関数がどのように機能するか (デフォルトの引数を含む) を理解すると、ライブラリのドキュメントを読むことができるようになります。

## 7. ライブラリのインポート

Python の真の力はそのライブラリから得られます。ファイルの先頭でインポートします。

```python
import numpy as np           # numerical computing
```

`as np` の部分はエイリアスを作成します。`numpy.array()` の代わりに `np.array()` と入力します。これは標準的な慣例です。

**これが AI にとって重要な理由**: すべての AI ワークフローはインポートから始まります。上記 3 つ (NumPy、Pandas、Matplotlib) は、ほぼすべてのデータ サイエンス ノートブックに記載されています。

## 8. NumPy の基本

NumPy は、Python の数値計算の基礎です。その中心となるオブジェクトは **配列** です。

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**これが AI にとって重要な理由**: ニューラル ネットワークの重み、画像のピクセル データ、単語の埋め込みはすべて NumPy 配列として保存されます。 `X_train.shape == (1000, 28, 28)` と表示されている場合、それは、それぞれ 28×28 ピクセルの 1,000 個の画像の NumPy 配列です。

## 9. パンダの基本

Pandas は、表形式のデータ (Python のスプレッドシート) を操作するためのものです。

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**これが AI にとって重要な理由**: 現実世界のデータセットは CSV ファイルとして提供されます。 Pandas は、モデルをトレーニングする前にデータをロード、探索、クリーンアップ、準備する方法です。

## 10. 完全なミニ例

データをロードして分割し、単純なモデルをトレーニングして評価する完全な Python スクリプトを次に示します。

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**この内容を 1 行ずつ読んでください。** 上記の概念を理解すれば、この内容を 1 行ずつ理解できます。それが目標です。ML コードを最初から書くのではなく、それを読み、理解し、変更できるようにすることです。
