# AI 教育アカデミーを設立した理由

AI はあらゆる業界を再構築していますが、ほとんどの AI 教育はペイウォールの内側に閉じ込められており、英語のみで書かれており、コーディングの方法をすでに知っていることを前提としています。私たちはそれを変えることに着手しました。

＃＃ 問題

AI を学び始めたとき、世界の大部分を妨げている 3 つの障壁に気づきました。

1. **言語** — ほぼすべての質の高い AI コースは英語で行われます。これでは何十億人もの学習者が除外されます。
2. **料金** — プレミアム AI コースの範囲は 50 ドルから 500 ドル以上です。発展途上国の学生にとって、それは初歩的なことではありません。
3. **前提条件** — ほとんどのコースは「まず、Python をインストールします...」で始まります。技術的な背景がない人はすぐに疎外されてしまいます。

これらは小さなギャップではありません。これらは、AI リテラシーを少数の裕福な英語圏コミュニティに集中させ続ける壁です。

## 私たちのソリューション

AI Educademy は、あなたの言語で AI を絶対ゼロから教える **無料のオープンソース プラットフォーム**です。開始するためにコーディングは必要ありません。クレジットカードは必要ありません。これまで。

### 何が違うのか

- **11 言語** — 英語、フランス語、オランダ語、ヒンディー語、テルグ語、スペイン語、ポルトガル語、ドイツ語、中国語、日本語、アラビア語。さらに登場します。
- **2 つの学習トラック** — 概念的な理解のための *AI ラーニング パス* (🌱 シード → 🌲 フォレスト) と、実践的な構築のための *クラフト エンジニアリング パス* (✏️ スケッチ → 🏆 マスターピース)。
- **10 の構造化プログラム** - それぞれに注意深く順序付けられた MDX レッスン、インタラクティブな要素、および進捗状況の追跡が含まれています。
- **インタラクティブ ラボ** - ニューラル ネットワーク プレイグラウンド、プロンプト ラボ、センチメント アナライザーを含む 7 つの実験 - すべてブラウザーで実行されます。
- **AI を活用した機能** — 弊社の組み込みチャットボットである Edu が、あらゆるプログラムに関する質問に答えます。模擬面接シミュレーターは、フィードバック付きで現実的な STAR 方式の面接を実施します。
- **修了証明書** — プログラムのすべてのレッスンを完了し、パーソナライズされた PDF 証明書をダウンロードします。

## アーキテクチャ

私たちは AI Educademy を最新の構成可能なプラットフォームとして構築しました。

```
┌─────────────────────────────────────────────┐
│              aieducademy.org                 │
│         Next.js 16 + React 19               │
│      ┌──────────┐  ┌──────────────┐         │
│      │  MDX      │  │  Interactive │         │
│      │  Lessons  │  │  Lab         │         │
│      └────┬─────┘  └──────┬───────┘         │
│           │               │                  │
│      ┌────▼───────────────▼──────┐           │
│      │     Content Layer         │           │
│      │  (Git Submodules per      │           │
│      │   program — own repos)    │           │
│      └───────────────────────────┘           │
│                                              │
│      ┌─────────┐  ┌──────────┐  ┌────────┐  │
│      │ Auth    │  │ Progress │  │ AI Chat│  │
│      │ NextAuth│  │ Neon PG  │  │ Gemini │  │
│      └─────────┘  └──────────┘  └────────┘  │
└──────────────────────────────────────────────┘
```

各コースは独自の GitHub リポジトリに存在し、Git サブモジュールとしてプラットフォームに取り込まれます。これはつまり：

- **コンテンツ作成者**は、プラットフォーム コードに触れることなくレッスンを作成できます。
- **翻訳者**は、コース リポジトリにフォルダーを作成することで言語を追加できます。
- **コンテンツ リポジトリが変更をプッシュすると、プラットフォームは自動的に再構築されます**。

技術スタック: App Router + Turbopack を備えた Next.js 16、厳密モードの TypeScript、Tailwind CSS 4、i18n 用の next-intl、認証用の NextAuth v5、および永続化用の Neon Postgres。デザイン システムは [Storybook](https://aieducademy.github.io/ai-ui-library/) が公開された別個の npm パッケージ](https://www.npmjs.com/package/@aieducademy/ai-ui-library)] です。

## デフォルトでオープンソース

プラットフォーム コードのすべての行は MIT ライセンスを取得しており、[GitHub](https://github.com/ai-educademy)] で入手できます。私たちは、教育インフラは公共財であるべきだと信じています。

次のことができます。
- 学校または組織のプラットフォーム全体を **セルフホスト** します。
- コース リポジトリを **フォーク**して、カリキュラムに合わせて調整します。
- **貢献** 翻訳、レッスン、バグ修正、または機能。

## 次は何ですか

まだ始まったばかりです。私たちのロードマップでは:

- 🌍 **さらに多くの言語** — コミュニティ主導の翻訳ポータルが近日公開されます。
- 🔌 **LMS 統合** — 大学および学校向けの LTI サポート。
- 🧪 **インタラクティブなコード演習** — 即時のフィードバックを備えたブラウザ内コーディング。
- 📱 **モバイル アプリ** — AI 教育をオフラインで利用します。
- 🎯 **パーソナライズされた学習パス** — 進捗状況に基づいた AI を活用した推奨事項。
