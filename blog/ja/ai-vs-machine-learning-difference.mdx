最近テクノロジーについて 5 分以上読んだ人なら、これら 3 つの用語が同じ意味で、そして間違って使用されているのを見たことがあるでしょう。 「AI」は、スマートサーモスタットから自動運転車に至るまで、あらゆるものに導入されています。 「機械学習」というとロボットが歩き方を学習しているように聞こえます。そして「ディープラーニング」？まるで哲学の授業のような話ですね。

それを修正しましょう。このガイドを読み終える頃には、同僚、マネージャー、さらには祖父母にも、本当の違いを誰にでも説明できるようになります。

## それについて考える最も簡単な方法

3 つの同心円を描いてください。

- **最も外側の円**は **人工知能 (AI)** - 最も広い概念です
- 内部には AI のサブセットである **機械学習 (ML)** が組み込まれています
- 中心となるのは、ML のサブセットである **ディープ ラーニング (DL)** です。

すべての深層学習システムは機械学習システムです。すべての機械学習システムは AI システムです。ただし、すべての AI システムが機械学習を使用するわけではなく、すべての ML システムが深層学習を使用するわけでもありません。

それが構造的な答えです。では、それらが*なぜ*違うのかを理解しましょう。

## 人工知能: 大きな傘

**人工知能は、通常は人間の知能を必要とするタスクを実行するシステムの構築に特化したコンピューター サイエンスの分野です。**

それでおしまい。 「賢いことを行うマシン」以上の厳密な技術的定義はありません。

AI は包括的な用語であり、1950 年代から存在しています。アラン・チューリングが「機械は考えることができるのか？」と尋ねたとき、 1950年、彼はAIに質問をしていた。 1997年にIBMのディープ・ブルーがチェスの世界チャンピオン、ガルリ・カスパロフを破ったとき、それはAIだった。メールがスパムをフィルタリングしてくれるのは、AI です。

初期の AI システムは **手作りのルール** を使用して構築されました。プログラマは明示的な命令を次のように書きます。

```
IF the email contains "you've won a prize" AND sender is unknown
  THEN mark as spam
```

これは、**ルールベース AI** または **エキスパート システム** と呼ばれます。範囲が狭く、予測可能な問題に適しています。しかし、拡張性はありません。考えられるすべてのスパム パターン、すべてのチェスの局面、または文のあらゆる表現方法に対応するルールを作成することはできません。

この制限こそが、まさに機械学習をもたらしたものです。

### 現在 AI として重要なものは何ですか?

- 検索エンジンのランキング結果
- Siri や Alexa などの音声アシスタント
- 銀行での不正行為の検出
- 交通量を予測するナビゲーション アプリ
- あなたのプレイスタイルに適応するゲームの対戦相手
- Netflix または Spotify のレコメンデーション システム

これらはすべてAIです。 ML を使用するものもあります。深層学習を使用するものもあります。より単純なテクニックを使用するものもあります。

## 機械学習: データから学習する AI

**機械学習は、ルールを使用して明示的にプログラムされるのではなく、システムがデータからパターンを学習する AI のサブセットです。**

プログラマーが「電子メールに X と書かれている場合は、Y を実行する」と記述する代わりに、機械学習システムが何千ものスパム電子メールと非スパム電子メールの例でトレーニングされます。パターンを独自に把握します。

中心となるアイデア: **マシンに十分な例を与えると、ルール自体が一般化されます。**

### 3 種類の機械学習

**1.教師あり学習** — 最も一般的なタイプ。モデルに例 (入力 → 正しい出力) というラベルを付けると、モデルは新しい入力に対する出力を予測することを学習します。

*例*: ラベルが付いた猫と犬の 10,000 枚の写真でモデルをトレーニングします。新しい写真を分類する方法を学習します。

**2.教師なし学習** — ラベルなし。モデルはデータ内の構造を独自に検出します。

*例*: ラベルのない顧客の購入データをモデルに与えます。どのセグメントを見つけるべきかは指示されずに、顧客をセグメント (多額の支出をする人、時々購入する人、割引を求める人) にグループ化します。

**3.強化学習** — モデルは試行錯誤によって学習し、良い行動に対して報酬を受け取ります。

*例*: エージェントは、ランダムな動きを試し、ポイントを獲得すると報酬を受け取り、徐々に上達することでビデオ ゲームのプレイ方法を学びます。

### 従来の ML アルゴリズム

おそらく次のようなことについて聞いたことがあるでしょう。

- **線形回帰** — 数値 (サイズに基づく住宅価格) を予測します。
- **デシジョン ツリー** — データを分類するための決定のフローチャート
- **ランダム フォレスト** — 多数のディシジョン ツリーが一緒に投票します
- **サポート ベクター マシン (SVM)** — クラス間の最適な境界を見つける
- **K-Means Clustering** — データを K 個のクラスターにグループ化します。

これらのアルゴリズムはうまく機能しますが、**特徴エンジニアリング**、つまりデータのどの側面 (特徴) が重要かを人間が判断する必要があります。住宅価格モデルの場合は、平方フィート、寝室の数、近隣地域を手動で選択します。

画像用？猫を猫たらしめているものを手動で説明することはできません。そこでディープラーニングが登場します。

## 深層学習: ニューラル ネットワークを使用した ML

**ディープ ラーニングは、多くの層を持つ人工ニューラル ネットワークを使用して、生データから階層的特徴を自動的に学習する機械学習のサブセットです。**

重要な画期的な点は、ディープ ラーニングにより手動の特徴量エンジニアリングの必要性がなくなることです。生のピクセル、生のテキスト、または生の音声を与えると、何が重要かを独自に学習します。

### ニューラル ネットワークの仕組み (簡単に)

ニューラル ネットワークは人間の脳から大まかにインスピレーションを受けています。内容は以下のとおりです。

- **入力レイヤー** — 生データ (ピクセル、ワード、数値) を受け取ります
- **隠しレイヤー** — 数学的演算を通じてデータを処理および変換します
- **出力レイヤー** — 最終予測を生成します

深層学習における「深い」とは、*多くの* 隠れ層 (場合によっては数百) を持つことを指します。各層は、ますます抽象化された機能を学習します。

- **レイヤー 1**: 画像内のエッジを検出します
- **レイヤー 2**: エッジを組み合わせて形状を作成します
- **レイヤー 3**: シェイプをオブジェクトのパーツに結合します
- **レイヤー 4**: オブジェクト全体を認識します

人間がこれをするように指示したわけではありません。ネットワークは、数百万の画像のトレーニングを通じてこれらの表現を発見しました。

### ディープラーニングが今日力を与えているもの

最近見たほぼすべての優れた AI 機能の背後にはディープ ラーニングが組み込まれています。

|アプリケーション |ディープラーニングの種類 |
|---|---|
| ChatGPT、クロード、ジェミニ |トランスフォーマー (大規模言語モデル) |
| DALL-E、ミッドジャーニー、安定拡散 |普及モデル + CNN |
|リアルタイム音声認識 (Siri、Whisper) |リカレント ネットワーク / トランス |
|自動運転車の認識 |畳み込みニューラル ネットワーク (CNN) |
| AlphaFold タンパク質の折り畳み |グラフ ニューラル ネットワーク + アテンション |
| DeepMind の AlphaGo |強化学習 + CNN |

### ディープラーニングのトレードオフ

ディープラーニングは強力ですが、次のようなコストがかかります。

- **データが大量に必要**: 多くの場合、何百万ものトレーニング サンプルが必要になります
- **計算集約型**: 高価な GPU または TPU が必要です
- **ブラックボックス**: モデルが決定を下した理由を解釈するのが難しい
- **予期しない方法で失敗する可能性があります**: 入力へのわずかな変更により、奇妙なエラーが発生する可能性があります (敵対的な例)

## 並べて比較

| | AI |機械学習 |ディープラーニング |
|---|---|---|---|
| **定義** |賢いことをする機械 |データから学習する機械 |ディープ ニューラル ネットワークを使用した ML |
| **テクニック** |ルール、検索、ML、DL |回帰、ツリー、SVM、クラスタリング | CNN、RNN、トランスフォーマー |
| **特徴エンジニアリング** |さまざま |多くの場合手動 |自動 |
| **データ要件** |さまざま |中程度 |非常に高い |
| **コンピューティング要件** |低いものから高いものへ |低から中 |高 |
| **解釈可能性** |さまざま |一般に高い |一般に低い |
| **こんな用途に最適** |あらゆるインテリジェントなタスク |構造化データ、中程度の複雑さ |画像、テキスト、オーディオ、ビデオ |

## 実際の例: 不正行為の検出

同じ問題が各レベルでどのように見えるかを見てみましょう。

**ルールベースの AI**: 「新しいデバイスからの 5,000 ポンドを超える取引にはフラグを立てます。」
- 実装は早いですが、巧妙な詐欺を見落とし、正当な取引をブロックします。

**機械学習**: ラベル (不正/不正ではない) を使用した何百万もの過去のトランザクションでランダム フォレストをトレーニングします。明示的なルールなしで、時刻、場所、販売者の種類、デバイスの指紋などの複雑なパターンを学習します。
- はるかに良くなりましたが、銀行のデータ サイエンティストはどの機能を含めるかを慎重に選択する必要がありました。

**深層学習**: 生のトランザクション シーケンスを Transformer モデルにフィードします。顧客の取引履歴全体にわたる一時的なパターンを自動的に学習します。
- 最高のパフォーマンスですが、大量のデータと計算が必要であり、トランザクションにフラグが付けられた理由を説明するのが難しくなります。

## よくある誤解

**「AIは意識を持ち、乗っ取るだろう」**
現在の AI (最先端の LLM を含む) には、意識、意図、目標がありません。洗練されたパターンマッチャーです。 「AI 乗っ取り」シナリオには、まだ存在しない推測的な将来のシステム (汎用人工知能、AGI) が含まれます。

**「機械学習と AI は同じものです」**
ML は AI を構築するための 1 つのアプローチです。 ML をまったく使用しない AI システムもあります (ルールベースのエキスパート システム、手作りの検索アルゴリズムを使用するチェス エンジンなど)。

**「ディープラーニングは常に最良の選択です」**
構造化された表形式データ (スプレッドシート、データベース) の場合、勾配ブースティング (XGBoost、LightGBM) などの従来の ML 手法は、はるかに少ないデータとコンピューティングでディープ ラーニングよりも優れたパフォーマンスを発揮することがよくあります。ディープラーニングは、画像、テキスト、音声などの非構造化データで威力を発揮します。

## 語彙のカンニングペーパー

- **AI** — 幅広い分野
- **ML** — データから学習する
- **DL** — ニューラル ネットワークを使用した学習
- **LLM** — 大規模言語モデル (GPT-4、Claude、Gemini — テキストに適用された深層学習)
- **CNN** — 畳み込みニューラル ネットワーク (画像の深層学習)
- **Transformer** — 最新の LLM を強化するアーキテクチャ
- **トレーニング** — データからモデルを学習するプロセス
- **推論** — トレーニングされたモデルを使用して予測を行う
- **パラメータ** — モデル内の学習値 (GPT-4 には約 1.8 兆あると報告されています)
- **微調整** — 事前トレーニングされたモデルを特定のタスクに適応させる
