पाइथॉन AI की भाषा है। यदि आपने मशीन लर्निंग के बारे में पढ़ने में समय बिताया है, तो आपने ट्यूटोरियल, गिटहब रिपोज़, शोध पत्र और पाठ्यक्रमों में हर जगह पायथन कोड देखा है। आख़िरकार, आप इसे पढ़ना चाहेंगे, चलाना चाहेंगे, और शायद इसे संशोधित भी करना चाहेंगे।

अच्छी खबर: आपको पायथन विशेषज्ञ बनने की आवश्यकता नहीं है। आपको भाषा के एक केंद्रित उपसमुच्चय की आवश्यकता है। यह मार्गदर्शिका आपको बिल्कुल यही सिखाती है - एआई कोड को समझने और उसके साथ काम करने के लिए आवश्यक न्यूनतम पायथन - वास्तविक एमएल वर्कफ़्लो से लिए गए उदाहरणों के साथ।

## 1. चर और डेटा प्रकार

पायथन में, आप मानों को वेरिएबल्स में संग्रहीत करते हैं। किसी प्रकार की घोषणा की आवश्यकता नहीं है.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**एआई के लिए यह क्यों मायने रखता है**: मॉडल हाइपरपैरामीटर, सटीकता स्कोर और कॉन्फ़िगरेशन मान चर के रूप में संग्रहीत किए जाते हैं। आपको लगातार `learning_rate = 0.001` या `epochs = 50` जैसी चीजें दिखाई देंगी।

---

## 2. सूचियाँ

सूची वस्तुओं का क्रमबद्ध संग्रह है। आप एक वेरिएबल में एकाधिक मान संग्रहीत कर सकते हैं.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**यह AI के लिए क्यों मायने रखता है**: प्रशिक्षण इतिहास, लेबल की सूचियाँ, डेटा के बैच - सभी सूचियों में संग्रहीत (या NumPy सरणियाँ, जो समान रूप से काम करती हैं)।

---

## 3. शब्दकोश

शब्दकोश कुंजी-मूल्य जोड़े संग्रहीत करते हैं। इन्हें लेबल वाले बक्सों की तरह समझें।

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**एआई के लिए यह क्यों मायने रखता है**: मॉडल कॉन्फ़िगरेशन, प्रशिक्षण तर्क और परिणाम लगभग हमेशा शब्दकोशों के रूप में दर्शाए जाते हैं। जब आप AI कोड में `config = {...}` देखते हैं, तो यही होता है।

---

## 4. लूप्स

लूप्स आपको संग्रह में प्रत्येक आइटम के लिए एक क्रिया दोहराने देता है।

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**एआई के लिए यह क्यों मायने रखता है**: प्रशिक्षण लूप कई युगों के डेटा पर पुनरावृत्त होते हैं। डेटा प्रीप्रोसेसिंग लूप डेटासेट में प्रत्येक पंक्ति को साफ़ करते हैं। आप लगभग हर प्रशिक्षण स्क्रिप्ट में `for epoch in range(epochs):` देखेंगे।

---

## 5. कार्य

फ़ंक्शंस कोड के पुन: प्रयोज्य ब्लॉक हैं। आप उन्हें एक बार परिभाषित करें और उन्हें कई बार कॉल करें।

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

फ़ंक्शन में पैरामीटर के लिए डिफ़ॉल्ट मान हो सकते हैं:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**एआई के लिए यह क्यों मायने रखता है**: प्रत्येक एमएल लाइब्रेरी फ़ंक्शंस से बनी होती है। `model.fit()`, `model.predict()`, `train_test_split()` - ये सभी फ़ंक्शन कॉल हैं। यह समझना कि फ़ंक्शन कैसे काम करते हैं (डिफ़ॉल्ट तर्कों सहित) लाइब्रेरी दस्तावेज़ पढ़ने की आपकी क्षमता को अनलॉक करता है।

## 8. न्यूमपी मूल बातें

NumPy Python में संख्यात्मक कंप्यूटिंग की नींव है। इसका मुख्य उद्देश्य **सरणी** है।

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**यह AI के लिए क्यों मायने रखता है**: तंत्रिका नेटवर्क भार, छवि पिक्सेल डेटा, शब्द एम्बेडिंग - सभी NumPy सरणियों के रूप में संग्रहीत हैं। जब आप `X_train.shape == (1000, 28, 28)` देखते हैं, तो वह 1,000 छवियों की एक NumPy सरणी होती है, प्रत्येक 28×28 पिक्सेल।

## 9. पांडा मूल बातें

पांडाज़ सारणीबद्ध डेटा - पायथन में स्प्रेडशीट के साथ काम करने के लिए है।

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**एआई के लिए यह क्यों मायने रखता है**: वास्तविक दुनिया के डेटासेट सीएसवी फाइलों के रूप में आते हैं। पांडा यह है कि आप किसी मॉडल को प्रशिक्षित करने से पहले डेटा को कैसे लोड, एक्सप्लोर, साफ़ और तैयार करते हैं।

## 10. एक पूर्ण लघु उदाहरण

यहां एक संपूर्ण पायथन स्क्रिप्ट है जो डेटा लोड करती है, उसे विभाजित करती है, एक सरल मॉडल को प्रशिक्षित करती है और उसका मूल्यांकन करती है:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**इस पंक्ति को पंक्ति दर पंक्ति पढ़ें।** उपरोक्त अवधारणाओं से, आप इसकी प्रत्येक पंक्ति को समझ सकते हैं। यही लक्ष्य है - एमएल कोड को शुरू से लिखना नहीं, बल्कि इसे पढ़ने, समझने और संशोधित करने में सक्षम होना।
