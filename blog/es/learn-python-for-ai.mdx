## Configurando Python

Antes que nada, instale Python.

**La forma recomendada**: Instale [Miniconda](https://docs.conda.io/en/latest/miniconda.html), un administrador de distribución ligero de Python. Facilita la gestión de paquetes y entornos.

Una vez instalado, abra una terminal y escriba:
```
python --version
```

Si ves `Python 3.x.x`, estás listo. Puedes escribir y ejecutar Python en:
- **Jupyter Notebook**: la herramienta estándar para experimentos de IA (basada en navegador, interactiva)
- **VS Code**: un editor gratuito con excelente compatibilidad con Python
- **Google Colab**: gratuito, basado en navegador, no necesita instalación

Para aprender sobre IA, comience con Google Colab. Es gratis, se ejecuta en su navegador y tiene acceso a GPU.

## 1. Variables y tipos de datos

En Python, almacenas valores en variables. No se necesitan declaraciones de tipo.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**Por qué esto es importante para la IA**: los hiperparámetros del modelo, las puntuaciones de precisión y los valores de configuración se almacenan como variables. Verás cosas como `learning_rate = 0.001` o `epochs = 50` constantemente.

---

## 2. Listas

Una lista es una colección ordenada de elementos. Puede almacenar varios valores en una variable.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**Por qué esto es importante para la IA**: historiales de entrenamiento, listas de etiquetas, lotes de datos, todo almacenado en listas (o matrices NumPy, que funcionan de manera similar).

---

## 3. Diccionarios

Los diccionarios almacenan pares clave-valor. Piense en ellos como cajas etiquetadas.

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**Por qué esto es importante para la IA**: la configuración del modelo, los argumentos de entrenamiento y los resultados casi siempre se representan como diccionarios. Cuando ves `config = {...}` en el código AI, esto es lo que está sucediendo.

---

## 4. Bucles

Los bucles te permiten repetir una acción para cada elemento de una colección.

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**Por qué esto es importante para la IA**: los bucles de entrenamiento iteran sobre datos durante múltiples épocas. Los bucles de preprocesamiento de datos limpian cada fila de un conjunto de datos. Verás `for epoch in range(epochs):` en prácticamente todos los guiones de entrenamiento.

---

## 5. Funciones

Las funciones son bloques de código reutilizables. Los defines una vez y los llamas muchas veces.

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

Las funciones pueden tener valores predeterminados para los parámetros:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**Por qué esto es importante para la IA**: cada biblioteca de ML está compuesta de funciones. `model.fit()`, `model.predict()`, `train_test_split()`: todas estas son llamadas a funciones. Comprender cómo funcionan las funciones (incluidos los argumentos predeterminados) desbloquea su capacidad para leer la documentación de la biblioteca.

## 6. Condicionales

```python
accuracy = 0.92

if accuracy > 0.90:
    print("Model is performing well")
elif accuracy > 0.75:
    print("Model is acceptable")
else:
    print("Model needs improvement")
```

**Por qué esto es importante para la IA**: la lógica condicional aparece en la validación de datos, los criterios de parada temprana y la toma de decisiones durante la inferencia.

## 7. Importación de bibliotecas

El verdadero poder de Python proviene de sus bibliotecas. Los importas en la parte superior de tu archivo.

```python
import numpy as np           # numerical computing
import pandas as pd          # data manipulation
import matplotlib.pyplot as plt   # plotting
```

La parte `as np` crea un alias: escribe `np.array()` en lugar de `numpy.array()`. Esta es una convención estándar.

**Por qué esto es importante para la IA**: cada flujo de trabajo de IA comienza con las importaciones. Los tres anteriores (NumPy, Pandas y Matplotlib) aparecen prácticamente en todos los cuadernos de ciencia de datos.

## 8. Conceptos básicos de NumPy

NumPy es la base de la computación numérica en Python. Su objeto principal es **matriz**.

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**Por qué esto es importante para la IA**: pesos de redes neuronales, datos de píxeles de imágenes, incrustaciones de palabras, todo almacenado como matrices NumPy. Cuando vea `X_train.shape == (1000, 28, 28)`, es una matriz NumPy de 1000 imágenes, cada una de 28 × 28 píxeles.

## 9. Conceptos básicos de los pandas

Pandas sirve para trabajar con datos tabulares: hojas de cálculo en Python.

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**Por qué esto es importante para la IA**: los conjuntos de datos del mundo real vienen como archivos CSV. Pandas es la forma de cargar, explorar, limpiar y preparar datos antes de entrenar un modelo.

## 10. Un mini ejemplo completo

Aquí hay un script Python completo que carga datos, los divide, entrena un modelo simple y lo evalúa:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**Lea esto línea por línea.** Con los conceptos anteriores, podrá comprender cada línea. Ese es el objetivo: no escribir código ML desde cero, sino poder leerlo, comprenderlo y modificarlo.
