## 1. Variablen und Datentypen

In Python speichern Sie Werte in Variablen. Keine Typdeklarationen erforderlich.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**Warum das für KI wichtig ist**: Modellhyperparameter, Genauigkeitswerte und Konfigurationswerte werden als Variablen gespeichert. Sie werden ständig Dinge wie `learning_rate = 0.001` oder `epochs = 50` sehen.

---

## 2. Listen

Eine Liste ist eine geordnete Sammlung von Elementen. Sie können mehrere Werte in einer Variablen speichern.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**Warum das für KI wichtig ist**: Trainingsverläufe, Etikettenlisten, Datenstapel – alles in Listen (oder NumPy-Arrays, die ähnlich funktionieren) gespeichert.

---

## 3. Wörterbücher

Wörterbücher speichern Schlüssel-Wert-Paare. Betrachten Sie sie als beschriftete Kisten.

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**Warum das für KI wichtig ist**: Modellkonfiguration, Trainingsargumente und Ergebnisse werden fast immer als Wörterbücher dargestellt. Wenn Sie `config = {...}` im AI-Code sehen, passiert Folgendes.

---

## 4. Schleifen

Mit Schleifen können Sie eine Aktion für jedes Element in einer Sammlung wiederholen.

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**Warum das für KI wichtig ist**: Trainingsschleifen iterieren über Daten für mehrere Epochen. Datenvorverarbeitungsschleifen bereinigen jede Zeile in einem Datensatz. Sie werden `for epoch in range(epochs):` in praktisch jedem Trainingsskript sehen.

---

## 5. Funktionen

Funktionen sind wiederverwendbare Codeblöcke. Sie definieren sie einmal und rufen sie mehrmals auf.

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

Funktionen können Standardwerte für Parameter haben:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**Warum das für KI wichtig ist**: Jede ML-Bibliothek besteht aus Funktionen. `model.fit()`, `model.predict()`, `train_test_split()` – das sind alles Funktionsaufrufe. Wenn Sie verstehen, wie Funktionen funktionieren (einschließlich Standardargumente), können Sie Bibliotheksdokumentation lesen.

## 6. Bedingungen

```python
accuracy = 0.92

if accuracy > 0.90:
```

## 7. Bibliotheken importieren

Die wahre Stärke von Python liegt in seinen Bibliotheken. Sie importieren sie oben in Ihre Datei.

```python
import numpy as np           # numerical computing
import pandas as pd          # data manipulation
import matplotlib.pyplot as plt   # plotting
```

Der Teil `as np` erstellt einen Alias ​​– Sie geben `np.array()` anstelle von `numpy.array()` ein. Dies ist eine Standardkonvention.

**Warum das für KI wichtig ist**: Jeder KI-Workflow beginnt mit Importen. Die drei oben genannten – NumPy, Pandas und Matplotlib – erscheinen in praktisch jedem Data-Science-Notizbuch.

## 8. NumPy-Grundlagen

NumPy ist die Grundlage des numerischen Rechnens in Python. Sein Kernobjekt ist das **Array**.

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**Warum das für KI wichtig ist**: Neuronale Netzwerkgewichte, Bildpixeldaten, Worteinbettungen – alles als NumPy-Arrays gespeichert. Wenn Sie `X_train.shape == (1000, 28, 28)` sehen, handelt es sich um ein NumPy-Array mit 1.000 Bildern mit jeweils 28 x 28 Pixeln.

## 9. Pandas-Grundlagen

Pandas dient der Arbeit mit tabellarischen Daten – Tabellenkalkulationen in Python.

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**Warum das für KI wichtig ist**: Reale Datensätze liegen als CSV-Dateien vor. Mit Pandas laden, erkunden, bereinigen und bereiten Sie Daten vor, bevor Sie ein Modell trainieren.

## 10. Ein vollständiges Mini-Beispiel

Hier ist ein vollständiges Python-Skript, das Daten lädt, aufteilt, ein einfaches Modell trainiert und auswertet:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**Lesen Sie dies Zeile für Zeile durch.** Mit den oben genannten Konzepten können Sie jede einzelne Zeile verstehen. Das ist das Ziel – nicht, ML-Code von Grund auf zu schreiben, sondern ihn lesen, verstehen und ändern zu können.
