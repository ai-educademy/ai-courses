## Erstens: Welche Art von KI möchten Sie lernen?

„Lernende KI“ bedeutet je nach Ziel ganz unterschiedliche Dinge. Entscheiden Sie vor dem Eintauchen, welche davon Sie am besten beschreibt:

**Pfad A – KI-Benutzer/Power-User**
Sie möchten KI-Tools effektiv für Ihren Job oder Ihr Unternehmen nutzen: schnelles Engineering, Erstellen mit KI-APIs, Automatisierung von Arbeitsabläufen. Sie müssen keine Modelle trainieren.
*Zeitplan: 4–8 Wochen, um hochqualifiziert zu werden.*

**Pfad B – KI-Praktiker / ML-Ingenieur**
Sie möchten Modelle für maschinelles Lernen erstellen, trainieren und bereitstellen. Sie arbeiten mit Daten, schreiben ML-Code und lösen echte Probleme.
*Zeitrahmen: 6–18 Monate für solide Grundlagen.*

**Pfad C – KI-Forscher**
Sie möchten die Grenzen dessen erweitern, was KI leisten kann – Veröffentlichungen veröffentlichen, neue Architekturen erfinden, Grundlagenarbeit leisten.
*Zeitplan: Erfordert normalerweise einen Master- oder Ph.D.-Abschluss; 3–6+ Jahre.*

Die meisten Leute, die dies lesen, befinden sich auf Pfad A oder Pfad B. Dieser Leitfaden deckt beide ab und ist in jeder Phase deutlich gekennzeichnet.

## Die Voraussetzungen (nicht überspringen)

### Programmierung: Python ist nicht verhandelbar (für Pfad B)

Python ist die Sprache der KI und des maschinellen Lernens. Wenn Sie Python nicht kennen, beginnen Sie hier. Sie müssen kein Experte sein – Sie müssen sich mit dem Lesen und Schreiben von Code auskennen.

**Was Sie lernen sollten:**
- Variablen, Datentypen, Listen, Wörterbücher
- Schleifen (`for`, `while`) und Bedingungen (`if/else`)
- Funktionen und Module
- Datei-E/A
- Grundlegende objektorientierte Programmierung

**Kostenlose Ressourcen:**
- [Offizielles Tutorial von Python.org](https://docs.python.org/3/tutorial/)
- [Automatisieren Sie langweilige Dinge mit Python](https://automatetheboringstuff.com/) – kostenlos online, praktisch, ausgezeichnet
- Der Python-Kurs von freeCodeCamp auf YouTube

**Zeitschätzung**: 4–6 Wochen, wenn Sie konsequent sind (1–2 Stunden pro Tag)

### Mathematik: Wie viel brauchst du eigentlich?

Hier geraten Menschen unnötigerweise in Panik. Hier ist die ehrliche Antwort:

**Für die Verwendung von KI-Tools (Pfad A)**: Keine Mathematik erforderlich. Ernsthaft.

**Für die Erstellung von ML-Modellen (Pfad B)**: Sie benötigen praktische Kenntnisse in:
- **Lineare Algebra**: Vektoren, Matrizen, Matrixmultiplikation – wie Daten dargestellt werden
- **Infinitesimalrechnung**: Ableitungen, die Kettenregel – wie Modelle durch Gradientenabstieg lernen
- **Wahrscheinlichkeit und Statistik**: Verteilungen, Mittelwert/Varianz, Satz von Bayes – wie mit Unsicherheit umgegangen wird

Sie müssen **nicht** in der Lage sein, Theoreme zu beweisen. Sie benötigen Intuition und die Fähigkeit, Gleichungen zu lesen.

**Kostenlose Ressourcen:**
- [3Blue1Brown's Essence of Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab) – die beste visuelle Erklärung, kostenlos auf YouTube
- [3Blue1Brown's Essence of Calculus](https://www.youtube.com/playlist?list=PLZHQObOWTQDMsr9K-rj53DwVRMYO3t5Yr) – gleiche Qualität
- Khan Academy Statistics and Probability – umfassend und kostenlos

**Zeitschätzung**: 6–10 Wochen sanftes Lernen neben Python

## Stufe 2: Kern maschinelles Lernen (Pfad B – 8–12 Wochen)

Hier erfahren Sie mehr über die eigentliche Mechanik. Arbeiten Sie die Grundlagen in dieser Reihenfolge durch:

### 2a. Datenverarbeitung mit NumPy und Pandas

Bevor Sie Modelle erstellen, müssen Sie Daten verarbeiten. NumPy und Pandas sind die grundlegenden Python-Bibliotheken für numerische Berechnungen und Datenmanipulation.

```python
import pandas as pd

# Load a dataset
df = pd.read_csv('housing_data.csv')

# Explore it
print(df.head())
print(df.describe())

# Handle missing values
df = df.dropna()

# Feature selection
X = df[['bedrooms', 'bathrooms', 'sqft']]
y = df['price']
```

**Ressource**: [Kaggles kostenloser Pandas-Mikrokurs](https://www.kaggle.com/learn/pandas) – 4 Stunden, praktisch

### 2b. Scikit-Learn für klassisches ML

Scikit-Learn ist die Python-Bibliothek der Wahl für traditionelles maschinelles Lernen. Es umfasst Implementierungen von Dutzenden von Algorithmen mit einer konsistenten, sauberen API.

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, predictions):.2f}")
```

Durcharbeiten: lineare Regression, logistische Regression, Entscheidungsbäume, zufällige Wälder, K-Means-Clustering und SVMs. Verstehen Sie, wann Sie sie verwenden sollten.

**Ressource**: [Offizielle Tutorials von Scikit-Learn](https://scikit-learn.org/stable/tutorial/) + [Kaggles ML-Mikrokurse](https://www.kaggle.com/learn)

### 2c. Ihr erstes echtes Projekt

Lernen ohne Bauen ist Auswendiglernen ohne Verstehen. Wählen Sie einen Datensatz aus (Kaggle ist voll davon) und erstellen Sie ein End-to-End-Modell:

1. Laden und erkunden Sie die Daten (EDA)
2. Reinigen und vorverarbeiten
3. Wählen Sie ein Modell aus und trainieren Sie es
4. Bewerten Sie die Leistung
5. Tunen Sie es und verbessern Sie es
6. Schreiben Sie auf, was Sie gelernt haben

**Meilenstein**: Ein trainiertes ML-Modell auf einem echten Datensatz, veröffentlicht auf GitHub.

## Stufe 3: Deep Learning (Pfad B – 8–12 Wochen)

Jetzt sind Sie bereit, in neuronale Netze einzutauchen.

### 3a. PyTorch oder TensorFlow?

Dies sind die beiden vorherrschenden Deep-Learning-Frameworks. Die ehrliche Empfehlung im Jahr 2026: **Starten Sie mit PyTorch**. Es ist pythonischer, wird häufiger in der Forschung verwendet und ist einfacher zu debuggen. TensorFlow/Keras wird in der Produktion immer noch häufig verwendet, aber PyTorch ist der Hauptanreiz.

```python
import torch
import torch.nn as nn

# Define a simple neural network
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        return self.layers(x)

model = SimpleNet()
```

### 3b. Wichtige Deep-Learning-Konzepte, die es zu meistern gilt

- **Forward Pass und Backpropagation** – wie Modelle lernen
- **Aktivierungsfunktionen** – ReLU, Sigmoid, Softmax
- **Verlustfunktionen** – Kreuzentropie, MSE
- **Optimierer** – SGD, Adam
- **Regularisierung** – Dropout, Batch-Normalisierung
- **Convolutional Neural Networks (CNNs)** – für Bilder
- **Recurrent Neural Networks (RNNs)** – für Sequenzen
- **Die Transformer-Architektur** – die Grundlage moderner LLMs

**Ressourcen:**
- [fast.ai Practical Deep Learning](https://course.fast.ai/) – von oben nach unten, praktisch
- [Andrej Karpathys Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) – erstellt ein GPT von Grund auf

**Meilenstein**: Erstellen und trainieren Sie ein neuronales Netzwerk von Grund auf (nicht nur den Aufruf eines vorgefertigten Modells).

## Stufe 4: Arbeiten mit LLMs (beide Wege – 4–6 Wochen)

Im Jahr 2026 ist es unerlässlich, zu verstehen, wie man mit großen Sprachmodellen arbeitet, unabhängig von Ihrem Weg.

### Für Pfad A (mit LLMs):
- Lernen Sie Prompt Engineering gründlich kennen – Null-Schuss, Wenig-Schuss, Gedankenkette
- Verstehen Sie RAG (Retrieval-Augmented Generation) – die Kombination von LLMs mit Ihren eigenen Daten
- Erstellen Sie einfache Anwendungen mit der OpenAI-API, der Anthropic-API oder Open-Source-Modellen

### Für Pfad B (Bauen mit LLMs):
- Verstehen Sie die Transformer-Architektur genau (Aufmerksamkeitsmechanismus, Positionskodierung)
- Lernen Sie die Feinabstimmung mit Hugging Face Transformers
- Parametereffiziente Feinabstimmung verstehen (LoRA, QLoRA)
- Experimentieren Sie mit Open-Source-Modellen (Llama, Mistral, Phi)

```python
from transformers import pipeline

# Using a pre-trained model in 3 lines
summariser = pipeline("summarization", model="facebook/bart-large-cnn")
result = summariser("Your long text here...", max_length=130)
print(result[0]['summary_text'])
```

## Häufige Fehler, die es zu vermeiden gilt

**Tutorial-Hölle** – Tutorial nach Tutorial ansehen, ohne etwas zu bauen. Wenden Sie nach jedem Tutorial das Gelernte sofort auf ein Projekt an.

**Versuchen Sie, alles zu verstehen, bevor Sie beginnen** – Sie müssen die Mathematik nicht beherrschen, bevor Sie mit dem Code in Berührung kommen. Intuition entsteht durch Handeln.

**Allein lernen** – Finden Sie eine Community. Nehmen Sie an AI Discord-Servern, Kaggle-Wettbewerben oder einem strukturierten Lernprogramm teil.

**Die Grundlagen überspringen** – Wenn Sie direkt mit der Feinabstimmung von LLMs beginnen, ohne den Gradientenabstieg zu verstehen, entstehen Lücken, die Sie später beißen.

**Auf der Suche nach neuen Dingen** – Die KI-Landschaft ändert sich wöchentlich. Beherrschen Sie die Grundlagen, die sich langsam ändern, bevor Sie jeder neuen Modellveröffentlichung nachjagen.
