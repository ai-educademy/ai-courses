## Beginnen Sie hier: Die biologische Inspiration

Ihr Gehirn enthält etwa 86 Milliarden Neuronen. Jedes Neuron ist eine Zelle, die elektrische Signale von anderen Neuronen empfängt, einen kleinen Teil der Verarbeitung durchführt und entscheidet, ob sie ein Signal an die Neuronen weiterleitet, mit denen sie verbunden ist.

Das Entscheidende an Neuronen ist nicht das Individuum, sondern die *Verbindungen zwischen ihnen*. Wenn Sie etwas Neues lernen, werden die Verbindungen zwischen Neuronen stärker oder schwächer. Das sind Gedächtnis, Geschicklichkeit und Wissen – alles kodiert als Verbindungsstärken.

Künstliche neuronale Netze übernehmen diese Idee direkt:
- **Künstliche Neuronen** empfangen Zahlen als Eingaben (anstelle elektrischer Signale)
- Jede Verbindung hat ein **Gewicht** (anstelle der synaptischen Stärke)
- Ein Neuron *feuert* (gibt einen Wert weiter), basierend auf einer Berechnung, die seine Eingaben und Gewichte umfasst
- Lernen bedeutet, *diese Gewichte anzupassen* – das gleiche Grundprinzip wie biologisches Lernen

Die biologische Analogie zerfällt auf der Detailebene schnell (echte Neuronen sind weitaus komplexer), aber die Kernidee ist eine echte Inspiration und nicht nur eine Metapher.

## Das Perzeptron: Das einfachste mögliche neuronale Netzwerk

Bevor es „tiefe“ Netzwerke gab, gab es das **Perzeptron** – 1958 von Frank Rosenblatt erfunden. Es ist der Baustein von allem, was folgt.

Ein Perzeptron ist ein einzelnes künstliches Neuron, das:

1. Nimmt mehrere Eingaben (Zahlen) entgegen
2. Multipliziert jede Eingabe mit einem Gewicht (ihrer Wichtigkeit)
3. Addiert die gewichteten Eingaben
4. Wendet einen Schwellenwert an: Gibt eine 1 aus, wenn die Summe über dem Schwellenwert liegt, 0, wenn dies nicht der Fall ist

Hier ist ein konkretes, nicht-mathematisches Beispiel:

Stellen Sie sich vor, Sie entscheiden heute, ob Sie laufen gehen wollen. Sie berücksichtigen drei Faktoren:

```
Input 1: Is it raining?      → 0 (no) or 1 (yes)
Input 2: Do I have time?     → 0 (no) or 1 (yes)
Input 3: Do I feel motivated?→ 0 (no) or 1 (yes)
```

Das Perzeptron weist Gewichtungen zu, je nachdem, wie wichtig die einzelnen Faktoren für Sie sind:

```
Weight 1 (rain matters a lot):       -2.0  (rain is a strong deterrent)
Weight 2 (having time is crucial):   +3.0
Weight 3 (motivation matters a bit): +1.0
```

Es multipliziert jede Eingabe mit ihrem Gewicht und summiert sie:

```
Sum = (0 × -2.0) + (1 × 3.0) + (0 × 1.0) = 3.0
```

Wenn die Summe über 2,0 (dem Schwellenwert) liegt, laufen Sie los. 3,0 > 2,0 → Du gehst laufen.

Das ist fast komisch einfach – aber es ist die grundlegende Berechnung, die, millionenfach gestapelt und auf Daten trainiert, Systeme hervorbringt, die Gedichte schreiben und Krebs diagnostizieren können.

## Ebenen: Von einfach zu leistungsstark

Ein einzelnes Perzeptron kann nur sehr einfache Probleme lösen. Die Kraft entsteht durch die Verbindung von Perzeptronen zu **Schichten**.

Ein neuronales Netzwerk besteht aus drei Arten von Schichten:

```
INPUT LAYER      HIDDEN LAYER(S)     OUTPUT LAYER
───────────      ───────────────     ────────────
   ●  ─────────→  ●  ─────────→  ●
   ●  ─────────→  ●  ─────────→  ●
   ●  ─────────→  ●              ●
                  ●
```

### Die Eingabeebene

Die Eingabeschicht empfängt Rohdaten. Bei einem Bild ist der Helligkeitswert jedes Pixels eine Eingabe. Bei Text erhält jedes Wort (oder jeder Wortteil) eine numerische Darstellung. Bei einem tabellarischen Datensatz ist jede Spalte eine Eingabe.

Hier findet keine Berechnung statt – es sind nur die Daten, die in das Netzwerk gelangen.

### Versteckte Ebenen

Hier geschieht die Magie. Zwischen Eingabe und Ausgabe liegen verborgene Schichten, die die Roheingaben in immer abstraktere Darstellungen umwandeln.

Eine hilfreiche Analogie: Stellen Sie sich vor, Sie versuchen herauszufinden, ob auf einem Foto eine Katze zu sehen ist.

- **Erste verborgene Ebene**: Erkennt einfache Muster – Kanten, Ecken, Farbverläufe.
- **Zweite verborgene Ebene**: Kombiniert diese Muster zu Formen – Ohren, Schnurrhaare, runde Augen.
- **Dritte verborgene Ebene**: Kombiniert Formen in Teile – Gesicht, Körper, Pfoten.
- **Ausgabeschicht**: Kombiniert Teile zu einer sicheren Entscheidung – „Ja, das ist eine Katze“ (97 %).

Jede Ebene abstrahiert von der vorherigen. Aus diesem Grund kommt es auf die Tiefe an und deshalb bedeutet „Deep Learning“ einfach „neuronale Netze mit vielen verborgenen Schichten“.

### Die Ausgabeschicht

Die Ausgabeschicht erzeugt die endgültige Antwort. Das Format hängt von der Aufgabe ab:

- **Binäre Klassifizierung** (Spam oder nicht Spam): Ein Ausgabeneuron, Wert zwischen 0 und 1.
- **Mehrklassenklassifizierung** (welche von 10 Ziffern?): Zehn Ausgabeneuronen, eines pro Klasse.
- **Regression** (Preis vorhersagen): Ein Ausgabeneuron, eine beliebige reelle Zahl.
- **Sequenzgenerierung** (das nächste Wort vorhersagen): Viele Ausgabeneuronen, eines pro mögliches Wort.

## So funktioniert Training: Das Netzwerk lehren

Ein neuronales Netzwerk beginnt mit zufälligen Gewichten – es weiß nichts. Beim Training werden diese Gewichte wiederholt angepasst, bis das Netzwerk die richtigen Antworten gibt.

Hier ist die Trainingsschleife im Klartext:

### Schritt 1: Der Vorwärtspass

Führen Sie eine Eingabe Schicht für Schicht durch das Netzwerk, bis Sie eine Ausgabe erhalten. Bei zufälligen Anfangsgewichten ist diese Ausgabe falsch (oder zufällig). Das wird erwartet.

```
Input: [image of a dog]
Network output (before training): "cat" (67% confident)
Correct answer: "dog"
```

### Schritt 2: Berechnen Sie den Verlust

Der **Verlust** (oder Fehler) misst, wie falsch die Ausgabe war. Wenn wir 67 % Katze vorhergesagt haben und die richtige Antwort Hund (0 % Katze) war, ist der Verlust groß. Wenn wir einen Hund von 95 % vorhersagen, ist der Verlust gering.

Die Verlustfunktion lautet: „Wie haben wir uns geirrt?“ in eine einzige Zahl umwandeln, mit der wir mathematisch arbeiten können.

### Schritt 3: Backpropagation

Das ist der clevere Teil. Sobald Sie den Gesamtverlust kennen, verwendet das Netzwerk eine Technik namens **Backpropagation** (Backprop), um herauszufinden, *welche Gewichte* für den Fehler verantwortlich waren und *in welcher Höhe*.

Es arbeitet rückwärts durch das Netzwerk und berechnet für jedes Gewicht: „Wenn ich dieses Gewicht leicht erhöhe, steigt oder sinkt dann der Verlust?“ Diese Berechnung (technisch gesehen der Gradient) sagt jedem Gewicht, in welche Richtung es sich bewegen soll.

Die Intuition:

```
  Output is too "cat" → 
    → The "whisker detector" fired too strongly → 
      → The weights feeding into "whisker detector" are too high →
        → Reduce those weights slightly
```

### Schritt 4: Aktualisieren Sie die Gewichte

Mithilfe der Steigungen des Backprops werden alle Gewichte leicht in die Richtung verschoben, die den Verlust verringert. Dieser Schubvorgang wird als **Gradientenabstieg** bezeichnet.

Die Größe jedes Anstoßes wird durch die **Lernrate** gesteuert – eine kritische Einstellung. Wenn es zu groß ist, schießt das Netzwerk über die Maßen und springt hin und her. Zu klein und das Training dauert ewig.

### Wiederholen, tausende Male

Ein Vorwärtspass + Backprop + Gewichtsaktualisierung ist ein *Trainingsschritt*. Ein Netzwerk könnte anhand von Millionen von Beispielen trainiert werden, die jeweils diesen Prozess durchlaufen. Im Laufe der Zeit pendeln sich die Gewichte auf Werte ein, die für eine Vielzahl von Eingaben korrekte Antworten liefern.

Das bedeutet „Training“ eines KI-Modells. Es geht nicht um Programmierregeln, sondern um die Optimierung von Millionen von Zahlen (Gewichten) durch wiederholte Auseinandersetzung mit Beispielen.

## Aktivierungsfunktionen: Nichtlinearität hinzufügen

Damit das alles funktioniert, ist noch eine weitere Zutat nötig: **Aktivierungsfunktionen**.

Hier liegt das Problem: Wenn jedes Neuron seine Eingaben einfach mit Gewichten multipliziert und addiert, entspricht das gesamte Netzwerk mathematisch einer einzelnen linearen Gleichung – egal wie viele Schichten Sie hinzufügen. Sie würden die gesamte Ausdruckskraft der Tiefe verlieren.

Aktivierungsfunktionen führen zu Nichtlinearität – sie werden auf die Ausgabe jedes Neurons angewendet und ermöglichen es dem Netzwerk, komplexe, gekrümmte Muster statt nur gerader Linien zu lernen.

Im Klartext:

- **ReLU (Rectified Linear Unit)**: „Wenn der Wert negativ ist, wird Null ausgegeben. Wenn positiv, wird er unverändert weitergegeben.“ Einfach, effektiv und am häufigsten verwendet. Betrachten Sie es als ein Einbahntor.
- **Sigmoid**: Staucht jede Zahl in einen Bereich zwischen 0 und 1. Nützlich für Ausgabeebenen bei der Binärklassifizierung – es stellt auf natürliche Weise die Wahrscheinlichkeit dar.
- **Softmax**: Wie Sigmoid, aber für mehrere Klassen – wandelt eine Liste von Zahlen in eine Wahrscheinlichkeitsverteilung um, deren Summe 1 ergibt. Wird bei Klassifizierungsaufgaben verwendet.
- **Tanh**: Ähnlich wie Sigmoid, liegt jedoch im Bereich von -1 bis 1. Wird häufig in wiederkehrenden Netzwerken verwendet.

Sie müssen diese nicht auswendig lernen. Die wichtigste Erkenntnis ist: Aktivierungsfunktionen ermöglichen es tiefen Netzwerken, komplexe, nichtlineare Muster in Daten zu lernen.

## Arten neuronaler Netze

Moderne KI nutzt mehrere spezialisierte Architekturen, die jeweils für unterschiedliche Datentypen geeignet sind.

### Convolutional Neural Networks (CNNs) 🖼️

**Am besten für**: Bilder und Videos.

CNNs verwenden einen speziellen Schichttyp namens Faltungsschicht, der kleine Filter auf ein Bild anwendet, um lokale Muster (Kanten, Texturen) zu erkennen. Diese Filter gleiten über das Bild, ähnlich wie man mit einer Lupe darüber fährt, um nach bestimmten Merkmalen zu suchen.

Die entscheidende Erkenntnis ist die **Parameterfreigabe** – derselbe Filter wird auf das gesamte Bild angewendet, was bedeutet, dass ein „vertikaler Kantendetektor“, der in der oberen linken Ecke funktioniert, überall funktioniert. Dies macht CNNs für Bilder wesentlich effizienter als normale Netzwerke.

**Echte Beispiele**: Gesichtserkennung von Google Fotos, Instagram-Filter, medizinische Bildgebung (Erkennung von Tumoren in Röntgenstrahlen), selbstfahrende Auto-Sichtsysteme.

### Wiederkehrende neuronale Netze (RNNs) 🔄

**Am besten geeignet für**: Sequenzen – Text, Zeitreihen, Sprache.

RNNs verarbeiten Sequenzen Schritt für Schritt und behalten dabei einen „verborgenen Zustand“ bei, der Informationen aus vorherigen Schritten weiterleitet. Dadurch verfügen sie über eine Art Kurzzeitgedächtnis.

Analogie: Wenn Sie diesen Satz lesen, vergessen Sie den Anfang nicht, wenn Sie am Ende angelangt sind. RNNs verfügen über eine ähnliche Fähigkeit, den Kontext über eine Sequenz hinweg aufrechtzuerhalten.

**Einschränkung**: RNNs haben Probleme mit langen Sequenzen. Informationen von vor vielen Schritten verblassen tendenziell. Dies führte zur LSTM-Architektur (Long Short-Term Memory), die explizite „Speicherzellen“ hinzufügte, um längere Abhängigkeiten zu bewältigen.

**Echte Beispiele**: Frühzeitige Spracherkennung, Übersetzung, Textvorhersage auf mobilen Tastaturen.

### Transformers 🔁

**Am besten für**: Alles, zunehmend.

Transformatoren sind die Architektur hinter GPT, BERT, DALL-E und den meisten modernen KI-Systemen. Sie wurden 2017 erfunden und revolutionierten das Feld, indem sie die Einschränkungen von RNNs mit einem Mechanismus namens **Selbstaufmerksamkeit** lösten.

Durch die Selbstaufmerksamkeit kann das Modell alle Positionen in einer Sequenz gleichzeitig betrachten – nicht nur Schritt für Schritt – und dynamisch gewichten, welche Teile der Eingabe für jede Ausgabe am relevantesten sind. Bei der Verarbeitung von „Das Ufer am Fluss war steil“ kann das Modell „Ufer“ mit „Fluss“ und „steil“ verbinden, um richtig zu verstehen, dass es nicht um Finanzen geht.

Transformatoren lassen sich außerdem sehr gut auf moderner Hardware (GPUs) parallelisieren, sodass es praktisch ist, sie auf Datensätze im Internetmaßstab zu trainieren. Aus diesem Grund dominieren sie seit 2017 die KI.

**Echte Beispiele**: ChatGPT, Claude, Gemini (Text); DALL-E, Stabile Diffusion (Bilder); Flüstern (Spracherkennung); AlphaFold (Vorhersage der Proteinstruktur).

## Warum „Deep“ Learning? Warum ist Tiefe wichtig?

„Deep Learning“ bedeutet lediglich neuronale Netze mit vielen verborgenen Schichten. Aber warum hilft mehr Tiefe?

Flachere Netzwerke können theoretisch jede Funktion annähern – aber sie würden dafür astronomisch viele Neuronen benötigen. Tiefe Netzwerke lernen **hierarchische Darstellungen**, die effizienter sind und sich besser auf neue Daten verallgemeinern lassen.

Betrachten Sie die Sprache:
- Ein flaches Netzwerk könnte sich merken, dass bestimmte Wortkombinationen positiv oder negativ sind.
- Ein tiefes Netzwerk lernt Abstraktionen – Syntax, Semantik, Kontext, Implikation –, die es ihm ermöglichen, Sätze zu verarbeiten, die es nie gesehen hat.

In der Praxis ist die Tiefe eine der zuverlässigsten Methoden zur Verbesserung der Leistung neuronaler Netzwerke in praktisch allen Bereichen, weshalb der Trend konsequent zu größeren, tieferen Netzwerken geht.

## Die Trainingsdatenabhängigkeit

Neuronale Netze sind nur so gut wie ihre Trainingsdaten. Das ist verständnisvoll:

- **Mehr Daten im Allgemeinen = bessere Leistung.** GPT-4 wurde auf Billionen von Text-Tokens trainiert. Dieser Maßstab ist der Grund, warum es so leistungsfähig ist.
- **Müll rein, Müll raus.** Wenn Trainingsdaten Verzerrungen, Fehler oder Lücken enthalten, lernt das Netzwerk diese. Dies ist die Hauptursache für die meisten Probleme mit der Fairness und Genauigkeit der KI.
- **Verteilungsverschiebung.** Ein Netzwerk, das auf Daten von 2020 trainiert ist, wird mit Konzepten zu kämpfen haben, die im Jahr 2025 entstanden sind. Es weiß nicht, was es nicht weiß.

Wenn Sie diese Einschränkungen verstehen, können Sie KI-Tools viel besser nutzen – Sie wissen, wann Sie der Ausgabe vertrauen und wann Sie sie überprüfen müssen.

## Das Fazit

Neuronale Netze sind keine Zauberei – sie sind eine clevere Kombination einfacher Operationen (Multiplizieren, Addieren, Vergleichen), die in enormem Umfang angewendet werden. Die „Intelligenz“ ergibt sich aus den beim Training erlernten Mustern, nicht aus einer individuellen Berechnung.

Was sie mächtig macht:
- **Tiefe** ermöglicht das Erlernen hierarchischer Darstellungen
- **Backpropagation** ermöglicht eine effiziente Gewichtsanpassung aufgrund von Fehlern
- **Skalierung** – sowohl in Parametern als auch in Trainingsdaten – ermöglicht die Verallgemeinerung

Was sie begrenzt:
- Sie benötigen riesige Mengen an Trainingsdaten
- Sie lernen Zusammenhänge, nicht kausales Verständnis
- Sie können getrost auf eine Art und Weise falsch liegen, wie es Menschen nicht tun würden

Das ist das ehrliche Bild. Das Verständnis beider Seiten unterscheidet nachdenkliche KI-Anwender von Menschen, die entweder unkritisch erstaunt oder reflexartig skeptisch sind.
