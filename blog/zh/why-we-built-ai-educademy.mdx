# 为什么我们建立人工智能教育学院

人工智能正在重塑每个行业——但大多数人工智能教育都被锁定在付费墙后面，仅用英语编写，并且假设你已经知道如何编码。我们着手改变这一现状。

＃＃ 问题

当我开始学习人工智能时，我注意到三个障碍将世界上大多数人拒之门外：

1. **语言**——几乎所有优质人工智能课程都是英语。这排除了数十亿学习者。
2. **成本** — 高级人工智能课程从 50 美元到 500 美元以上不等。对于发展中经济体的学生来说，这是不可能的。
3. **先决条件** - 大多数课程都以“首先，安装Python...”开头 - 立即疏远任何没有技术背景的人。

这些差距可不小。它们是让人工智能素养集中在少数富裕的英语社区的围墙。

## 我们的解决方案

AI Educademy 是一个**免费的开源平台**，用您的语言从零开始教授人工智能。无需编码即可启动。无需信用卡。曾经。

### 是什么让它与众不同

- **11 种语言** — 英语、法语、荷兰语、印地语、泰卢固语、西班牙语、葡萄牙语、德语、中文、日语和阿拉伯语。更多即将到来。
- **两条学习路径** — *人工智能学习路径*（🌱种子→🌲森林）用于概念理解，*工艺工程路径*（✏️草图→🏆杰作）用于动手建造。
- **10 个结构化课程** — 每个课程都有精心排序的 MDX 课程、互动元素和进度跟踪。
- **交互式实验室** - 七个实验，包括神经网络游乐场、提示实验室和情绪分析器 - 全部在浏览器中运行。
- **人工智能驱动的功能** — Edu，我们的内置聊天机器人，可以回答有关任何程序的问题。模拟面试模拟器可进行真实的 STAR 方法面试并提供反馈。
- **结业证书** — 完成课程中的所有课程并下载个性化的 PDF 证书。

## 架构

我们将 AI Educademy 打造为一个现代的、可组合的平台：

```
┌─────────────────────────────────────────────┐
│              aieducademy.org                 │
│         Next.js 16 + React 19               │
│      ┌──────────┐  ┌──────────────┐         │
│      │  MDX      │  │  Interactive │         │
│      │  Lessons  │  │  Lab         │         │
│      └────┬─────┘  └──────┬───────┘         │
│           │               │                  │
│      ┌────▼───────────────▼──────┐           │
│      │     Content Layer         │           │
│      │  (Git Submodules per      │           │
│      │   program — own repos)    │           │
│      └───────────────────────────┘           │
│                                              │
│      ┌─────────┐  ┌──────────┐  ┌────────┐  │
│      │ Auth    │  │ Progress │  │ AI Chat│  │
│      │ NextAuth│  │ Neon PG  │  │ Gemini │  │
│      └─────────┘  └──────────┘  └────────┘  │
└──────────────────────────────────────────────┘
```

每门课程都位于自己的 GitHub 存储库中，作为 git 子模块拉入平台。这意味着：

- **内容作者**可以在不接触平台代码的情况下编写课程。
- **翻译人员**可以通过在任何课程存储库中创建文件夹来添加语言。
- **当任何内容存储库推送更改时，平台会自动重建**。

技术堆栈：带有 App Router + Turbopack 的 Next.js 16、严格模式下的 TypeScript、Tailwind CSS 4、用于 i18n 的 next-intl、用于身份验证的 NextAuth v5 以及用于持久性的 Neon Postgres。设计系统是一个[单独的 npm 包](https://www.npmjs.com/package/@aieducademy/ai-ui-library)，带有已发布的 [Storybook](https://aieducademy.github.io/ai-ui-library/)]。

## 默认开源

每行平台代码均获得 MIT 许可，并可在 [GitHub](https://github.com/ai-educademy) 上获取。我们认为教育基础设施应该是公共产品。

您可以：
- **为您的学校或组织自行托管**整个平台。
- **分叉**课程存储库并根据您的课程进行调整。
- **贡献**翻译、课程、错误修复或功能。
