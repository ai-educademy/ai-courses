## 第一：你想学什么类型的人工智能？

根据您的目标，“学习人工智能”的含义也截然不同。在深入研究之前，请确定以下哪一项最能描述您：

**路径 A — AI 用户/高级用户**
您希望在工作或业务中有效地使用 AI 工具：快速工程、使用 AI API 进行构建、自动化工作流程。您不需要训练模型。
*时间线：4-8 周即可变得高度熟练。*

**路径 B — AI 从业者/机器学习工程师**
您想要构建、训练和部署机器学习模型。您将处理数据、编写机器学习代码并解决实际问题。
*时间表：6-18 个月打下坚实的基础。*

**路径 C — 人工智能研究员**
你想要突破人工智能的界限——发表论文、发明新架构、做基础工作。
*时间表：通常需要硕士或博士学位； 3–6 年以上。*

大多数阅读本文的人都在路径 A 或路径 B 上。本指南涵盖了这两种路径，并在每个阶段都有清晰的标记。

## 先决条件（不要跳过这个）

### 编程：Python 是不可协商的（对于路径 B）

Python 是人工智能和机器学习的语言。如果您不了解 Python，请从这里开始。您不需要成为专家 - 您需要足够舒适地阅读和编写代码。

**学习什么：**
- 变量、数据类型、列表、字典
- 循环 (`for`, `while`) 和条件 (`if/else`)
- 功能和模块
- 文件输入/输出
- 基本的面向对象编程

**免费资源：**
- [Python.org 官方教程](https://docs.python.org/3/tutorial/)
- [用Python自动化无聊的事情](https://automatetheboringstuff.com/)——免费在线，实用，优秀
- YouTube 上的 freeCodeCamp 的 Python 课程

**时间估计**：如果您坚持的话，需要 4-6 周（每天 1-2 小时）

### 数学：你实际上需要多少？

这就是人们不必要的恐慌的地方。这是诚实的答案：

**对于使用人工智能工具（路径 A）**：不需要数学。严重地。

**为了构建机器学习模型（路径 B）**：您需要具备以下方面的应用知识：
- **线性代数**：向量、矩阵、矩阵乘法——数据如何表示
- **微积分**：导数、链式法则——模型如何通过梯度下降学习
- **概率和统计**：分布、均值/方差、贝叶斯定理 - 如何处理不确定性

您**不需要**需要能够证明定理。您需要直觉和阅读方程式的能力。

**免费资源：**

## 第 2 阶段：核心机器学习（路径 B — 8–12 周）

这是您了解实际机制的地方。按以下顺序完成基础知识：

### 2a。使用 NumPy 和 Pandas 进行数据处理

在构建模型之前，您需要处理数据。 NumPy 和 Pandas 是用于数值计算和数据操作的基础 Python 库。

```python
import pandas as pd

# Load a dataset
df = pd.read_csv('housing_data.csv')

# Explore it
print(df.head())
print(df.describe())

# Handle missing values
df = df.dropna()

# Feature selection
X = df[['bedrooms', 'bathrooms', 'sqft']]
y = df['price']
```

**资源**：【Kaggle 的免费 Pandas 微课程](https://www.kaggle.com/learn/pandas) — 4 小时，动手实践

### 2b。用于经典 ML 的 Scikit-Learn

Scikit-Learn 是传统机器学习的首选 Python 库。它包含数十种算法的实现以及一致、干净的 API。

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, predictions):.2f}")
```

解决：线性回归、逻辑回归、决策树、随机森林、k 均值聚类和 SVM。了解何时使用每一个。

**资源**：【Scikit-Learn 官方教程](https://scikit-learn.org/stable/tutorial/) + 【Kaggle ML 微课程](https://www.kaggle.com/learn)】

### 2c。你的第一个真正的项目

没有构建的学习就是没有理解的记忆。选择一个数据集（Kaggle 中有很多这样的数据集）并构建一个端到端模型：

1. 加载并探索数据（EDA）
2. 清洗和预处理
3. 选择并训练模型
4. 评估其性能
5. 调整并改进
6.写下你学到的东西

**里程碑**：在真实数据集上训练的 ML 模型，发布到 GitHub。

## 第 3 阶段：深度学习（路径 B — 8–12 周）

现在您已准备好深入研究神经网络。

### 3a。 PyTorch 还是 TensorFlow？

这是两个占主导地位的深度学习框架。 2026 年诚实的建议：**从 PyTorch 开始**。它更Pythonic，在研究中使用更广泛，并且更容易调试。 TensorFlow/Keras 仍在生产中广泛使用，但 PyTorch 才是发展动力所在。

```python
import torch
import torch.nn as nn

# Define a simple neural network
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        return self.layers(x)

model = SimpleNet()
```

### 3b。需要掌握的关键深度学习概念

- **前向传播和反向传播** - 模型如何学习
- **激活函数** — ReLU、sigmoid、softmax
- **损失函数** — 交叉熵，MSE
- **优化者** — SGD，Adam
- **正则化** — dropout，批量标准化
- **卷积神经网络 (CNN)** — 用于图像
- **循环神经网络 (RNN)** — 用于序列
- **Transformer 架构** — 现代法学硕士的基础

**资源：**
- 【fast.ai实用深度学习](https://course.fast.ai/)——自上而下，实用
- [Andrej Karpathy 的神经网络：从零到英雄](https://karpathy.ai/zero-to-hero.html) — 从头开始构建 GPT

## 要避免的常见错误

**教程地狱** — 不断观看教程而不构建任何东西。每次教程结束后，立即将您学到的知识应用到项目中。

**开始之前尝试理解一切** — 在接触代码之前，您不需要掌握数学。直觉来自于实践。

**独自学习** — 寻找社区。加入 AI Discord 服务器、Kaggle 竞赛或结构化学习计划。

**跳过基础知识**——在不了解梯度下降的情况下直接跳到微调法学硕士将会留下稍后困扰你的空白。

**追逐新事物**——人工智能格局每周都在变化。在追逐每个新模型发布之前，先掌握变化缓慢的基础知识。
