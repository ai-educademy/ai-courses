## Configurando Python

Antes de mais nada, instale o Python.

**A maneira recomendada**: Instale [Miniconda](https://docs.conda.io/en/latest/miniconda.html), um gerenciador de distribuição Python leve. Isso simplifica o gerenciamento de pacotes e ambientes.

Depois de instalado, abra um terminal e digite:
```
python --version
```

Se você vir `Python 3.x.x`, você está pronto. Você pode escrever e executar Python em:
- **Jupyter Notebook** — a ferramenta padrão para experimentos de IA (baseados em navegador, interativos)
- **VS Code** — um editor gratuito com excelente suporte a Python
- **Google Colab** — gratuito, baseado em navegador, sem necessidade de instalação

Para aprendizado de IA, comece com Google Colab. É gratuito, roda no seu navegador e tem acesso à GPU.

## 1. Variáveis ​​e tipos de dados

Em Python, você armazena valores em variáveis. Nenhuma declaração de tipo é necessária.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**Por que isso é importante para a IA**: hiperparâmetros do modelo, pontuações de precisão e valores de configuração são armazenados como variáveis. Você verá coisas como `learning_rate = 0.001` ou `epochs = 50` constantemente.

---

## 2. Listas

Uma lista é uma coleção ordenada de itens. Você pode armazenar vários valores em uma variável.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**Por que isso é importante para a IA**: históricos de treinamento, listas de rótulos, lotes de dados — todos armazenados em listas (ou arrays NumPy, que funcionam de forma semelhante).

---

## 3. Dicionários

Os dicionários armazenam pares de valores-chave. Pense neles como caixas etiquetadas.

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**Por que isso é importante para a IA**: A configuração do modelo, os argumentos de treinamento e os resultados são quase sempre representados como dicionários. Quando você vê `config = {...}` no código AI, é isso que está acontecendo.

---

## 4. Loops

Os loops permitem repetir uma ação para cada item de uma coleção.

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**Por que isso é importante para a IA**: Os loops de treinamento iteram os dados em várias épocas. Os loops de pré-processamento de dados limpam cada linha em um conjunto de dados. Você verá `for epoch in range(epochs):` em praticamente todos os scripts de treinamento.

---

## 5. Funções

Funções são blocos de código reutilizáveis. Você os define uma vez e os chama várias vezes.

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

As funções podem ter valores padrão para parâmetros:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**Por que isso é importante para a IA**: toda biblioteca de ML é composta de funções. `model.fit()`, `model.predict()`, `train_test_split()` — todas são chamadas de função. Compreender como as funções funcionam (incluindo argumentos padrão) desbloqueia sua capacidade de ler a documentação da biblioteca.

## 6. Condicionais

```python
accuracy = 0.92

if accuracy > 0.90:
    print("Model is performing well")
elif accuracy > 0.75:
    print("Model is acceptable")
else:
    print("Model needs improvement")
```

**Por que isso é importante para a IA**: A lógica condicional aparece na validação de dados, nos critérios de parada antecipada e na tomada de decisões durante a inferência.

## 7. Importando Bibliotecas

O verdadeiro poder do Python vem de suas bibliotecas. Você os importa na parte superior do seu arquivo.

```python
import numpy as np           # numerical computing
import pandas as pd          # data manipulation
import matplotlib.pyplot as plt   # plotting
```

A parte `as np` cria um alias – você digita `np.array()` em vez de `numpy.array()`. Esta é uma convenção padrão.

**Por que isso é importante para a IA**: Todo fluxo de trabalho de IA começa com importações. Os três acima – NumPy, Pandas e Matplotlib – aparecem em praticamente todos os cadernos de ciência de dados.

## 8. Noções básicas de NumPy

NumPy é a base da computação numérica em Python. Seu objeto principal é o **array**.

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**Por que isso é importante para a IA**: pesos de redes neurais, dados de pixels de imagens, incorporações de palavras — todos armazenados como matrizes NumPy. Quando você vê `X_train.shape == (1000, 28, 28)`, é um array NumPy de 1.000 imagens, cada uma com 28×28 pixels.

## 9. Noções básicas de pandas

Pandas serve para trabalhar com dados tabulares – planilhas em Python.

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**Por que isso é importante para a IA**: Os conjuntos de dados do mundo real vêm como arquivos CSV. Pandas é como você carrega, explora, limpa e prepara dados antes de treinar um modelo.

## 10. Um mini exemplo completo

Aqui está um script Python completo que carrega dados, os divide, treina um modelo simples e os avalia:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**Leia isto linha por linha.** Com os conceitos acima, você pode entender cada linha dele. Esse é o objetivo: não escrever código de ML do zero, mas ser capaz de lê-lo, compreendê-lo e modificá-lo.
