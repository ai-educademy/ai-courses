## 1. Variabelen en gegevenstypen

In Python sla je waarden op in variabelen. Geen typeverklaringen nodig.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**Waarom dit belangrijk is voor AI**: modelhyperparameters, nauwkeurigheidsscores en configuratiewaarden worden opgeslagen als variabelen. Je ziet constant dingen als `learning_rate = 0.001` of `epochs = 50`.

---

## 2. Lijsten

Een lijst is een geordende verzameling items. U kunt meerdere waarden in één variabele opslaan.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**Waarom dit belangrijk is voor AI**: trainingsgeschiedenissen, lijsten met labels, batches met gegevens - allemaal opgeslagen in lijsten (of NumPy-arrays, die op dezelfde manier werken).

---

## 3. Woordenboeken

Woordenboeken slaan sleutel-waardeparen op. Zie ze als gelabelde dozen.

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**Waarom dit belangrijk is voor AI**: modelconfiguratie, trainingsargumenten en resultaten worden bijna altijd weergegeven als woordenboeken. Als je `config = {...}` in de AI-code ziet, is dit wat er gebeurt.

---

## 4. Lussen

Met lussen kun je een actie herhalen voor elk item in een verzameling.

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**Waarom dit belangrijk is voor AI**: trainingslussen herhalen gegevens voor meerdere tijdperken. Gegevensvoorverwerkingslussen reinigen elke rij in een gegevensset. Je ziet `for epoch in range(epochs):` in vrijwel elk trainingsscript.

---

## 5. Functies

Functies zijn herbruikbare codeblokken. Je definieert ze één keer en roept ze vele malen op.

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

Functies kunnen standaardwaarden voor parameters hebben:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**Waarom dit belangrijk is voor AI**: elke ML-bibliotheek bestaat uit functies. `model.fit()`, `model.predict()`, `train_test_split()` — dit zijn allemaal functieaanroepen. Als u begrijpt hoe functies werken (inclusief standaardargumenten), wordt uw vermogen om bibliotheekdocumentatie te lezen ontgrendeld.

accuracy = 0.92

## 7. Bibliotheken importeren

De echte kracht van Python komt van zijn bibliotheken. Je importeert ze bovenaan je bestand.

```python
import numpy as np           # numerical computing
import pandas as pd          # data manipulation
import matplotlib.pyplot as plt   # plotting
```

Het gedeelte `as np` maakt een alias aan: je typt `np.array()` in plaats van `numpy.array()`. Dit is een standaardconventie.

**Waarom dit belangrijk is voor AI**: elke AI-workflow begint met import. De drie bovenstaande – NumPy, Pandas en Matplotlib – verschijnen in vrijwel elk data science-notebook.

## 8. NumPy-basisprincipes

NumPy is de basis van numeriek computergebruik in Python. Het kernobject ervan is de **array**.

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**Waarom dit belangrijk is voor AI**: Neurale netwerkgewichten, afbeeldingspixelgegevens, woordinsluitingen - allemaal opgeslagen als NumPy-arrays. Als je `X_train.shape == (1000, 28, 28)` ziet, is dat een NumPy-array van 1000 afbeeldingen, elk 28×28 pixels.

## 9. Basisprincipes van panda's

Pandas is bedoeld voor het werken met tabelgegevens: spreadsheets in Python.

```python
import pandas as pd

# Load a CSV file
df = pd.read_csv("data.csv")

# Explore the data
print(df.head())         # first 5 rows
print(df.shape)          # (rows, columns)
print(df.columns)        # column names
print(df.describe())     # statistics

# Select a column
ages = df["age"]

# Filter rows
adults = df[df["age"] >= 18]

# Check for missing values
print(df.isnull().sum())
```

**Waarom dit belangrijk is voor AI**: datasets uit de echte wereld worden geleverd als CSV-bestanden. Panda's is de manier waarop u gegevens laadt, verkent, opschoont en voorbereidt voordat u een model traint.

## 10. Een compleet minivoorbeeld

Hier is een compleet Python-script dat gegevens laadt, splitst, een eenvoudig model traint en evalueert:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**Lees dit regel voor regel door.** Met de bovenstaande concepten kunt u elke regel ervan begrijpen. Dat is het doel: niet om vanuit het niets ML-code te schrijven, maar om deze te kunnen lezen, begrijpen en wijzigen.
