## أولاً: ما نوع الذكاء الاصطناعي الذي تريد أن تتعلمه؟

"تعلم الذكاء الاصطناعي" يعني أشياء مختلفة جدًا اعتمادًا على هدفك. قبل الغوص في الأمر، حدد أيًا مما يلي يصفك بشكل أفضل:

**المسار أ - مستخدم الذكاء الاصطناعي / المستخدم المتميز**
تريد استخدام أدوات الذكاء الاصطناعي بشكل فعال لعملك أو عملك: الهندسة السريعة، والبناء باستخدام واجهات برمجة تطبيقات الذكاء الاصطناعي، وأتمتة سير العمل. لا تحتاج إلى تدريب النماذج.
*الجدول الزمني: من 4 إلى 8 أسابيع لتصبح على درجة عالية من الكفاءة.*

**المسار ب - ممارس الذكاء الاصطناعي / مهندس تعلم الآلة**
تريد إنشاء نماذج للتعلم الآلي وتدريبها ونشرها. ستعمل مع البيانات وتكتب كود ML وتحل المشكلات الحقيقية.
*الجدول الزمني: من 6 إلى 18 شهرًا للأساسات الصلبة.*

**المسار ج - باحث الذكاء الاصطناعي**
أنت تريد تجاوز حدود ما يمكن أن يفعله الذكاء الاصطناعي، مثل نشر الأوراق البحثية، واختراع بنيات جديدة، والقيام بالأعمال التأسيسية.
*الجدول الزمني: عادة ما يتطلب درجة الماجستير أو الدكتوراه؛ من 3 إلى 6 سنوات فما فوق.*

معظم الأشخاص الذين يقرؤون هذا موجودون في المسار "أ" أو المسار "ب". ويغطي هذا الدليل كلا المسارين، مع وضع علامة واضحة في كل مرحلة.

### البرمجة: لغة بايثون غير قابلة للتفاوض (للمسار ب)

بايثون هي لغة الذكاء الاصطناعي والتعلم الآلي. إذا كنت لا تعرف لغة بايثون، فابدأ هنا. لست بحاجة إلى أن تكون خبيرًا، بل يجب أن تكون مرتاحًا بما يكفي لقراءة التعليمات البرمجية وكتابتها.

**ما يجب تعلمه:**
- المتغيرات وأنواع البيانات والقوائم والقواميس
- الحلقات (`for`، `while`) والشروط (`if/else`)
- الوظائف والوحدات
- ملف الإدخال/الإخراج
- البرمجة الشيئية الأساسية

**مصادر مجانية:**
- [البرنامج التعليمي الرسمي لـPython.org](https://docs.python.org/3/tutorial/)
- [أتمتة الأشياء المملة باستخدام Python](https://automatetheboringstuff.com/) - مجانًا عبر الإنترنت، وعملي، وممتاز
- دورة Python الخاصة بـ freeCodeCamp على YouTube

**تقدير الوقت**: من 4 إلى 6 أسابيع إذا كنت متسقًا (1-2 ساعة يوميًا)

### الرياضيات: ما المبلغ الذي تحتاجه فعليًا؟

هذا هو المكان الذي يشعر فيه الناس بالذعر دون داع. إليك الإجابة الصادقة:

**لاستخدام أدوات الذكاء الاصطناعي (المسار أ)**: لا حاجة إلى الرياضيات. بجد.

**لبناء نماذج تعلم الآلة (المسار ب)**: أنت بحاجة إلى معرفة عملية بما يلي:
- **الجبر الخطي**: المتجهات، المصفوفات، ضرب المصفوفات — كيفية تمثيل البيانات
- **حساب التفاضل والتكامل**: المشتقات، وقاعدة السلسلة — كيف تتعلم النماذج من خلال النسب المتدرج
- **الاحتمالات والإحصائيات**: التوزيعات، والمتوسط/التباين، ونظرية بايز — كيفية التعامل مع عدم اليقين

لا تحتاج إلى أن تكون قادرًا على إثبات النظريات. أنت بحاجة إلى الحدس والقدرة على قراءة المعادلات.

**مصادر مجانية:**

## المرحلة الثانية: التعلم الآلي الأساسي (المسار ب - 8-12 أسبوعًا)

هذا هو المكان الذي تدخل فيه في الميكانيكا الفعلية. العمل من خلال الأساسيات في هذا الترتيب:

###2أ. التعامل مع البيانات باستخدام NumPy وPandas

قبل بناء النماذج، تحتاج إلى التعامل مع البيانات. NumPy وPandas هما مكتبتا Python الأساسيتان للحساب العددي ومعالجة البيانات.

```python
import pandas as pd

# Load a dataset
df = pd.read_csv('housing_data.csv')

# Explore it
print(df.head())
print(df.describe())

# Handle missing values
df = df.dropna()

# Feature selection
X = df[['bedrooms', 'bathrooms', 'sqft']]
y = df['price']
```

**المصدر**: [دورة تدريبية صغيرة مجانية من Kaggle حول الباندا](https://www.kaggle.com/learn/pandas) — 4 ساعات، تدريب عملي

###2ب. Scikit-Learn لتعلم الآلة الكلاسيكي

Scikit-Learn هي مكتبة Python المخصصة للتعلم الآلي التقليدي. يتضمن تنفيذ العشرات من الخوارزميات مع واجهة برمجة تطبيقات متسقة ونظيفة.

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, predictions):.2f}")
```

العمل من خلال: الانحدار الخطي، والانحدار اللوجستي، وأشجار القرار، والغابات العشوائية، وتجميع الوسائل k، وSVMs. افهم متى تستخدم كل منها.

**المصدر**: [برامج Scikit-Learn التعليمية الرسمية](https://scikit-learn.org/stable/tutorial/) + [دورات Kaggle المصغرة لتعلم الآلة](https://www.kaggle.com/learn)

###2ج. مشروعك الحقيقي الأول

التعلم بلا بناء هو الحفظ بلا فهم. اختر مجموعة بيانات (Kaggle مليئة بها) وقم ببناء نموذج شامل:

1. تحميل واستكشاف البيانات (EDA)
2. قم بتنظيفه ومعالجته مسبقًا
3. اختر نموذجًا وقم بتدريبه
4. تقييم أدائها
5. ضبطه وتحسينه
6. اكتب ما تعلمته

**الحدث الرئيسي**: نموذج تعلم الآلة مُدرب على مجموعة بيانات حقيقية، تم نشره على GitHub.

## المرحلة 3: التعلم العميق (المسار ب - 8-12 أسبوعًا)

أنت الآن جاهز للتعمق في الشبكات العصبية.

###3أ. باي تورش أو TensorFlow؟

هذان هما إطارا التعلم العميق السائدان. التوصية الصادقة في عام 2026: **ابدأ بـ PyTorch**. إنها أكثر لغة بايثونية، وتستخدم على نطاق واسع في الأبحاث، وأسهل في تصحيح الأخطاء. لا يزال TensorFlow/Keras يستخدم على نطاق واسع في الإنتاج، ولكن PyTorch هو المكان الذي يوجد فيه الزخم.

```python
import torch
import torch.nn as nn

# Define a simple neural network
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        return self.layers(x)

model = SimpleNet()
```

###3ب. مفاهيم التعلم العميق الرئيسية لإتقانها

- **التمرير الأمامي والانتشار الخلفي** — كيف تتعلم النماذج
- **وظائف التنشيط** — ReLU، وsigmoid، وsoftmax
- **دوال الخسارة** — إنتروبيا متقاطعة، MSE
- **المتفائلون** — آدم، سنغافوري
- **التسوية** — التسرب، تسوية الدفعة
- **الشبكات العصبية التلافيفية (CNNs)** — للصور
- **الشبكات العصبية المتكررة (RNNs)** — للتسلسلات
- **هندسة المحولات** — أساس ماجستير إدارة الأعمال الحديث

**الموارد:**
- [fast.ai التعلم العميق العملي](https://course.fast.ai/) — من أعلى إلى أسفل، عملي
- [شبكات أندريه كارباثي العصبية: من الصفر إلى البطل](https://karpathy.ai/zero-to-hero.html) — إنشاء GPT من الصفر

**النقطة المهمة**: إنشاء شبكة عصبية وتدريبها من البداية (وليس مجرد استدعاء نموذج تم إنشاؤه مسبقًا).

## المرحلة 4: العمل مع ماجستير إدارة الأعمال (كلا المسارين - 4-6 أسابيع)

في عام 2026، يعد فهم كيفية العمل مع نماذج اللغات الكبيرة أمرًا ضروريًا بغض النظر عن المسار الخاص بك.

### بالنسبة للمسار أ (باستخدام ماجستير إدارة الأعمال):
- تعلم الهندسة السريعة بشكل كامل - صفر طلقة، طلقة قليلة، سلسلة من الأفكار
- فهم RAG (جيل الاسترجاع المعزز) - الجمع بين LLMs وبياناتك الخاصة
- إنشاء تطبيقات بسيطة باستخدام OpenAI API أو Anthropic API أو النماذج مفتوحة المصدر

### بالنسبة للمسار ب (البناء باستخدام ماجستير إدارة الأعمال):
- فهم بنية المحولات بعمق (آلية الانتباه، التشفير الموضعي)
- تعلم الضبط الدقيق باستخدام محولات الوجه المعانقة
- فهم الضبط الدقيق لكفاءة المعلمة (LoRA، QLoRA)
- تجربة النماذج مفتوحة المصدر (Llama، Mistral، Phi)

```python
from transformers import pipeline

# Using a pre-trained model in 3 lines
summariser = pipeline("summarization", model="facebook/bart-large-cnn")
result = summariser("Your long text here...", max_length=130)
print(result[0]['summary_text'])
```

## المرحلة الخامسة: التخصص وبناء المحفظة (مستمرة)

بعد الأساسيات، اختر التخصص بناءً على اهتماماتك:

- **رؤية الكمبيوتر** — تصنيف الصور، اكتشاف الكائنات، النماذج التوليدية (نمط DALL-E)
- ** البرمجة اللغوية العصبية / ماجستير إدارة الأعمال ** — فهم النص، وتوليده، وضبط نماذج اللغة
- **هندسة التعلم الآلي** — نشر النماذج في الإنتاج وعمليات MLOs والمراقبة
- **علوم البيانات** — تحليلات الأعمال، والنمذجة الإحصائية، واختبار A/B
- **الذكاء الاصطناعي لمجالات محددة** — الذكاء الاصطناعي للرعاية الصحية، وتعلم الآلة المالي، والأنظمة الذاتية
