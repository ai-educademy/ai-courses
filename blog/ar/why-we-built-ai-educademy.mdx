# لماذا قمنا ببناء أكاديمية الذكاء الاصطناعي التعليمية

يعيد الذكاء الاصطناعي تشكيل كل صناعة - ومع ذلك فإن معظم تعليم الذكاء الاصطناعي محصور خلف نظام حظر الاشتراك غير المدفوع، ومكتوب باللغة الإنجليزية فقط، ويفترض أنك تعرف بالفعل كيفية البرمجة. لقد شرعنا في تغيير ذلك.

## المشكلة

عندما بدأت تعلم الذكاء الاصطناعي، لاحظت ثلاثة عوائق أبقت معظم العالم خارجًا:

1. **اللغة** — جميع دورات الذكاء الاصطناعي عالية الجودة تقريبًا باللغة الإنجليزية. وهذا يستبعد مليارات المتعلمين.
2. **التكلفة** — تتراوح دورات الذكاء الاصطناعي المتميزة من 50 دولارًا إلى 500 دولار أو أكثر. بالنسبة للطلاب في الاقتصادات النامية، هذا أمر غير موفق.
3. **المتطلبات الأساسية** — تبدأ معظم الدورات التدريبية بـ "أولاً، قم بتثبيت Python..." - مما يؤدي إلى تنفير أي شخص ليس لديه خلفية تقنية على الفور.

هذه ليست فجوات صغيرة. إنها الجدران التي تحافظ على تركيز المعرفة بالذكاء الاصطناعي في عدد قليل من المجتمعات الثرية الناطقة باللغة الإنجليزية.

## الحل لدينا

AI Educademy عبارة عن **منصة مجانية مفتوحة المصدر** تقوم بتعليم الذكاء الاصطناعي من الصفر المطلق بلغتك. لا يوجد ترميز مطلوب للبدء. لا حاجة لبطاقة الائتمان. أبدًا.

### ما الذي يجعلها مختلفة

- **11 لغة** — الإنجليزية والفرنسية والهولندية والهندية والتيلجو والإسبانية والبرتغالية والألمانية والصينية واليابانية والعربية. المزيد قادم.
- **مساران تعليميان** — *مسار تعلم الذكاء الاصطناعي* (🌱 البذور → 🌲 الغابة) للفهم المفاهيمي، و *مسار الهندسة الحرفية* (✏️ رسم → 🏆 تحفة) للبناء العملي.
- **10 برامج منظمة** — يحتوي كل منها على دروس MDX المتسلسلة بعناية، والعناصر التفاعلية، وتتبع التقدم.
- **المختبر التفاعلي** — سبع تجارب تشمل ملعب الشبكة العصبية، والمختبر الفوري، ومحلل المشاعر — كلها تعمل في المتصفح.
- **ميزات مدعومة بالذكاء الاصطناعي** — Edu، برنامج الدردشة المدمج لدينا، يجيب على الأسئلة المتعلقة بأي برنامج. يقوم جهاز محاكاة Mock Interview بإجراء مقابلات واقعية بأسلوب STAR مع تقديم الملاحظات.
- **شهادات الإكمال** — أنهِ جميع الدروس في البرنامج وقم بتنزيل شهادة PDF مخصصة.

##الهندسة المعمارية

قمنا ببناء AI Educademy كمنصة حديثة وقابلة للتركيب:

```
┌─────────────────────────────────────────────┐
│              aieducademy.org                 │
│         Next.js 16 + React 19               │
│      ┌──────────┐  ┌──────────────┐         │
│      │  MDX      │  │  Interactive │         │
│      │  Lessons  │  │  Lab         │         │
│      └────┬─────┘  └──────┬───────┘         │
│           │               │                  │
│      ┌────▼───────────────▼──────┐           │
│      │     Content Layer         │           │
│      │  (Git Submodules per      │           │
│      │   program — own repos)    │           │
│      └───────────────────────────┘           │
│                                              │
│      ┌─────────┐  ┌──────────┐  ┌────────┐  │
│      │ Auth    │  │ Progress │  │ AI Chat│  │
│      │ NextAuth│  │ Neon PG  │  │ Gemini │  │
│      └─────────┘  └──────────┘  └────────┘  │
└──────────────────────────────────────────────┘
```

توجد كل دورة تدريبية في مستودع GitHub الخاص بها، ويتم سحبها إلى النظام الأساسي كوحدة فرعية لـ git. هذا يعنى:

- **مؤلفو المحتوى** يمكنهم كتابة الدروس دون لمس رمز المنصة.
- **المترجمون** يمكنهم إضافة لغة عن طريق إنشاء مجلد في أي مستودع للدورة التدريبية.
- ** تتم إعادة بناء النظام الأساسي تلقائيًا ** عندما يدفع أي مستودع محتوى إلى إجراء تغييرات.

المجموعة التقنية: Next.js 16 مع App Router + Turbopack، وTypeScript في الوضع الصارم، وTailwind CSS 4، وnext-intl لـ i18n، وNextAuth v5 للمصادقة، وNeon Postgres للاستمرارية. نظام التصميم عبارة عن [حزمة npm منفصلة](https://www.npmjs.com/package/@aieducademy/ai-ui-library) مع [Storybook](https://aieducademy.github.io/ai-ui-library/).

## مفتوح المصدر بشكل افتراضي

كل سطر من كود النظام الأساسي مرخص من MIT ومتوفر على [GitHub](https://github.com/ai-educademy). نحن نؤمن بأن البنية التحتية للتعليم يجب أن تكون منفعة عامة.

يمكنك:
- **الاستضافة الذاتية** للمنصة بأكملها لمدرستك أو مؤسستك.
- **Fork** مستودع الدورة التدريبية وتكييفه مع المنهج الدراسي الخاص بك.
- **المساهمة** في الترجمات أو الدروس أو إصلاحات الأخطاء أو الميزات.

## ما هو التالي

لقد بدأنا للتو. على خريطة الطريق لدينا:

- 🌍 **مزيد من اللغات** — ستتوفر قريبًا بوابة ترجمة موجهة من المجتمع.
- 🔌 **تكامل LMS** — دعم LTI للجامعات والمدارس.
- 🧪 **تمارين الأكواد التفاعلية** — الأكواد البرمجية داخل المتصفح مع تعليقات فورية.
- 📱 **تطبيق الهاتف المحمول** — نقل تعليم الذكاء الاصطناعي إلى وضع عدم الاتصال بالإنترنت.
- 🎯 **مسارات تعليمية مخصصة** — توصيات مدعومة بالذكاء الاصطناعي بناءً على تقدمك.
