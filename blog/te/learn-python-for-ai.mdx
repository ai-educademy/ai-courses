పైథాన్ AI యొక్క భాష. మీరు మెషిన్ లెర్నింగ్ గురించి చదవడానికి ఎప్పుడైనా గడిపినట్లయితే, మీరు ప్రతిచోటా పైథాన్ కోడ్‌ని చూసారు — ట్యుటోరియల్స్, GitHub రెపోలు, రీసెర్చ్ పేపర్లు మరియు కోర్సులలో. చివరికి, మీరు దీన్ని చదవాలనుకుంటున్నారు, దీన్ని అమలు చేయాలి మరియు సవరించవచ్చు.

శుభవార్త: మీరు పైథాన్ నిపుణుడిగా మారాల్సిన అవసరం లేదు. మీకు భాష యొక్క ఫోకస్ చేసిన ఉపసమితి అవసరం. ఈ గైడ్ మీకు సరిగ్గా బోధిస్తుంది — AI కోడ్‌ను అర్థం చేసుకోవడానికి మరియు పని చేయడానికి అవసరమైన కనీస పైథాన్ — నిజమైన ML వర్క్‌ఫ్లోల నుండి తీసుకోబడిన ఉదాహరణలతో.

ఇన్‌స్టాల్ చేసిన తర్వాత, టెర్మినల్‌ని తెరిచి టైప్ చేయండి:

## 1. వేరియబుల్స్ మరియు డేటా రకాలు

పైథాన్‌లో, మీరు విలువలను వేరియబుల్స్‌లో నిల్వ చేస్తారు. ఏ విధమైన ప్రకటనలు అవసరం లేదు.

```python
name = "neural network"       # string (text)
layers = 4                    # integer (whole number)
accuracy = 0.94               # float (decimal)
is_trained = True             # boolean (True/False)
```

**AI కోసం ఇది ఎందుకు ముఖ్యమైనది**: మోడల్ హైపర్‌పారామీటర్‌లు, ఖచ్చితత్వ స్కోర్‌లు మరియు కాన్ఫిగరేషన్ విలువలు వేరియబుల్స్‌గా నిల్వ చేయబడతాయి. మీరు `learning_rate = 0.001` లేదా `epochs = 50` వంటి వాటిని నిరంతరం చూస్తారు.

## 2. జాబితాలు

జాబితా అనేది వస్తువుల యొక్క ఆర్డర్ సేకరణ. మీరు ఒక వేరియబుల్‌లో బహుళ విలువలను నిల్వ చేయవచ్చు.

```python
scores = [0.82, 0.87, 0.91, 0.95]
labels = ["cat", "dog", "bird"]

# Access by index (starts at 0)
print(labels[0])    # "cat"
print(labels[-1])   # "bird" (last item)

# Add an item
labels.append("fish")

# Number of items
print(len(scores))  # 4
```

**AI కోసం ఇది ఎందుకు ముఖ్యమైనది**: శిక్షణ చరిత్రలు, లేబుల్‌ల జాబితాలు, డేటా బ్యాచ్‌లు — అన్నీ జాబితాలలో నిల్వ చేయబడతాయి (లేదా NumPy శ్రేణులు, అదే విధంగా పని చేస్తాయి).

## 3. నిఘంటువులు

నిఘంటువులు కీ-విలువ జతలను నిల్వ చేస్తాయి. వాటిని లేబుల్ బాక్సుల వలె భావించండి.

```python
model_config = {
    "learning_rate": 0.001,
    "batch_size": 32,
    "epochs": 10,
    "optimizer": "adam"
}

# Access a value
print(model_config["learning_rate"])    # 0.001

# Update a value
model_config["epochs"] = 20
```

**AI కోసం ఇది ఎందుకు ముఖ్యమైనది**: మోడల్ కాన్ఫిగరేషన్, శిక్షణ వాదనలు మరియు ఫలితాలు దాదాపు ఎల్లప్పుడూ నిఘంటువుల వలె సూచించబడతాయి. మీరు AI కోడ్‌లో `config = {...}`ని చూసినప్పుడు, ఇదే జరుగుతోంది.

## 4. లూప్స్

సేకరణలోని ప్రతి అంశానికి సంబంధించిన చర్యను పునరావృతం చేయడానికి లూప్‌లు మిమ్మల్ని అనుమతిస్తాయి.

```python
# for loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# range — loop a specific number of times
for i in range(5):
    print(i)    # prints 0, 1, 2, 3, 4
```

**AIకి ఇది ఎందుకు ముఖ్యమైనది**: శిక్షణ లూప్‌లు బహుళ యుగాల కోసం డేటాపై మళ్ళించబడతాయి. డేటా ప్రీప్రాసెసింగ్ లూప్‌లు డేటాసెట్‌లోని ప్రతి అడ్డు వరుసను శుభ్రపరుస్తాయి. మీరు వాస్తవంగా ప్రతి శిక్షణా స్క్రిప్ట్‌లో `for epoch in range(epochs):`ని చూస్తారు.

## 5. విధులు

విధులు కోడ్ యొక్క పునర్వినియోగ బ్లాక్‌లు. మీరు వాటిని ఒకసారి నిర్వచించండి మరియు చాలాసార్లు కాల్ చేయండి.

```python
def calculate_accuracy(correct, total):
    return correct / total

result = calculate_accuracy(85, 100)
print(result)    # 0.85
```

విధులు పారామితుల కోసం డిఫాల్ట్ విలువలను కలిగి ఉండవచ్చు:

```python
def train_model(data, epochs=10, learning_rate=0.001):
    print(f"Training for {epochs} epochs at lr={learning_rate}")

train_model(data)                          # uses defaults
train_model(data, epochs=20)               # override one
train_model(data, epochs=20, learning_rate=0.01)   # override both
```

**AIకి ఇది ఎందుకు ముఖ్యమైనది**: ప్రతి ML లైబ్రరీ ఫంక్షన్‌లతో రూపొందించబడింది. `model.fit()`, `model.predict()`, `train_test_split()` — ఇవన్నీ ఫంక్షన్ కాల్‌లు. ఫంక్షన్‌లు ఎలా పని చేస్తాయో అర్థం చేసుకోవడం (డిఫాల్ట్ ఆర్గ్యుమెంట్‌లతో సహా) లైబ్రరీ డాక్యుమెంటేషన్‌ను చదవగల మీ సామర్థ్యాన్ని అన్‌లాక్ చేస్తుంది.

```python
import numpy as np           # numerical computing
```

## 8. NumPy బేసిక్స్

NumPy అనేది పైథాన్‌లోని సంఖ్యా కంప్యూటింగ్‌కు పునాది. దీని ప్రధాన వస్తువు **శ్రేణి**.

```python
import numpy as np

# Create arrays
a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

# Operations apply element-wise
print(a + b)         # [11, 22, 33, 44, 55]
print(a * 2)         # [2, 4, 6, 8, 10]
print(np.mean(a))    # 3.0

# 2D arrays (matrices)
matrix = np.array([[1, 2], [3, 4], [5, 6]])
print(matrix.shape)  # (3, 2) — 3 rows, 2 columns
```

**AIకి ఇది ఎందుకు ముఖ్యమైనది**: న్యూరల్ నెట్‌వర్క్ బరువులు, ఇమేజ్ పిక్సెల్ డేటా, వర్డ్ ఎంబెడ్డింగ్‌లు — అన్నీ NumPy శ్రేణులుగా నిల్వ చేయబడతాయి. మీరు `X_train.shape == (1000, 28, 28)`ని చూసినప్పుడు, అది 1,000 చిత్రాల NumPy శ్రేణి, ప్రతి 28×28 పిక్సెల్‌లు.

## 10. పూర్తి చిన్న ఉదాహరణ

డేటాను లోడ్ చేసే, దానిని విభజించే, సాధారణ మోడల్‌కు శిక్షణ ఇచ్చే మరియు మూల్యాంకనం చేసే పూర్తి పైథాన్ స్క్రిప్ట్ ఇక్కడ ఉంది:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 1. Load data
df = pd.read_csv("customers.csv")

# 2. Separate features and target
X = df[["age", "income", "years_customer"]]
y = df["will_churn"]

# 3. Split into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 4. Train a model
model = LogisticRegression()
model.fit(X_train, y_train)

# 5. Evaluate
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)
print(f"Accuracy: {accuracy:.2%}")
```

**ఈ పంక్తుల వారీగా చదవండి.** పై కాన్సెప్ట్‌లతో, మీరు ప్రతి ఒక్క పంక్తిని అర్థం చేసుకోవచ్చు. అదే లక్ష్యం — ML కోడ్‌ను మొదటి నుండి వ్రాయడం కాదు, దాన్ని చదవడం, అర్థం చేసుకోవడం మరియు సవరించడం.

## మీకు ఏమి అవసరం లేదు (ఇంకా)

AI కోడ్‌తో ఆచరణాత్మకంగా ఉండటానికి, మీరు వెంటనే నేర్చుకోవాల్సిన అవసరం లేదు:

- ఆబ్జెక్ట్-ఓరియెంటెడ్ ప్రోగ్రామింగ్ (తరగతులు, వారసత్వం)
- డెకరేటర్లు మరియు అధునాతన పైథాన్ లక్షణాలు
- కరెన్సీ మరియు అసమకాలిక కోడ్
- పైథాన్ ప్యాకేజీలు మరియు మాడ్యూల్స్ రాయడం

మీరు మరింత లోతుగా వెళ్లేకొద్దీ ఇవి విలువైనవిగా మారతాయి, కానీ AI సాధనాలు మరియు ట్యుటోరియల్‌లతో పనిచేయడానికి ఇవి ముందస్తు అవసరం కావు.

## ఎక్కడ ప్రాక్టీస్ చేయాలి

- **[Google Colab](https://colab.research.google.com)** — GPU యాక్సెస్‌తో ఉచిత నోట్‌బుక్‌లు
- **[కాగ్లే లెర్న్](https://www.kaggle.com/learn)** — ఉచిత పైథాన్ మరియు ML మైక్రో కోర్సులు
- **[ఎక్సర్సిజం పైథాన్ ట్రాక్](https://exercism.org/tracks/python)** — మార్గదర్శకత్వంతో కూడిన వ్యాయామాలు

తెలుసుకోవడానికి ఉత్తమ మార్గం కోడ్‌ని అమలు చేయడం, విచ్ఛిన్నం చేయడం, దాన్ని పరిష్కరించడం మరియు ప్రయోగం చేయడం. మీకు ఆసక్తికరంగా అనిపించే అంశంపై కగ్గెల్ డేటాసెట్‌ను ఎంచుకుని, పాండాలతో దాన్ని అన్వేషించడం ప్రారంభించండి.

AI కోసం పైథాన్ పటిమ అంటే వాక్యనిర్మాణాన్ని గుర్తుంచుకోవడం కాదు. ఇది నమూనాలను గుర్తించడం గురించి — లూప్ ఎలా ఉంటుందో తెలుసుకోవడం, ఫంక్షన్ కాల్ ఏమి చేస్తుంది, దిగుమతి ఏమి తీసుకువస్తుంది. ఈ గైడ్‌లోని కాన్సెప్ట్‌లతో, AI ట్యుటోరియల్‌లను చదవడానికి, కోడ్ ఉదాహరణలతో పాటు అనుసరించడానికి మరియు మీరే ప్రయోగాలు చేయడానికి మీకు పునాది ఉంది.

AI ఫండమెంటల్స్ ద్వారా నిర్మాణాత్మక మార్గం కావాలా? [AI ఎడ్యుకాడెమీ](https://aieducademy.org) మీ స్వంత నమూనాలను రూపొందించడం మరియు శిక్షణ ఇవ్వడం ద్వారా AI యొక్క ప్రాథమిక అంశాల నుండి మిమ్మల్ని తీసుకెళ్లే ఉచిత కోర్సులను అందిస్తుంది - ముందస్తు అనుభవం అవసరం లేదు.
