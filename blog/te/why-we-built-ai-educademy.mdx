# మేము AI ఎడ్యుకాడెమీని ఎందుకు నిర్మించాము

AI ప్రతి పరిశ్రమను పునర్నిర్మిస్తోంది - అయినప్పటికీ చాలా AI విద్య పేవాల్‌ల వెనుక లాక్ చేయబడింది, ఇది ఆంగ్లంలో మాత్రమే వ్రాయబడింది మరియు మీకు ఇప్పటికే కోడ్ ఎలా చేయాలో తెలుసని ఊహిస్తుంది. మేము దానిని మార్చడానికి బయలుదేరాము.

## సమస్య

నేను AI నేర్చుకోవడం ప్రారంభించినప్పుడు, ప్రపంచంలోని చాలా ప్రాంతాలను దూరంగా ఉంచే మూడు అడ్డంకులను నేను గమనించాను:

1. **భాష** — దాదాపు అన్ని నాణ్యమైన AI కోర్సులు ఆంగ్లంలో ఉన్నాయి. ఇది బిలియన్ల మంది అభ్యాసకులను మినహాయించింది.
2. **ధర** — ప్రీమియం AI కోర్సులు $50 నుండి $500+ వరకు ఉంటాయి. అభివృద్ధి చెందుతున్న ఆర్థిక వ్యవస్థలలోని విద్యార్థులకు, ఇది నాన్-స్టార్టర్.
3. **అవసరాలు** — చాలా కోర్సులు "మొదట, పైథాన్‌ని ఇన్‌స్టాల్ చేయండి..."తో ప్రారంభమవుతాయి - సాంకేతిక నేపథ్యం లేని ఎవరినైనా వెంటనే దూరం చేస్తుంది.

ఇవి చిన్న ఖాళీలు కావు. అవి AI అక్షరాస్యతను సంపన్న, ఆంగ్లం మాట్లాడే కొన్ని సంఘాలలో కేంద్రీకరించే గోడలు.

## మా పరిష్కారం

AI ఎడ్యుకాడెమీ అనేది **ఉచిత, ఓపెన్ సోర్స్ ప్లాట్‌ఫారమ్** ఇది మీ భాషలో సంపూర్ణ సున్నా నుండి AIని బోధిస్తుంది. ప్రారంభించడానికి కోడింగ్ అవసరం లేదు. క్రెడిట్ కార్డ్ అవసరం లేదు. ఎప్పుడూ.

### దానికి భిన్నమైనది

- **11 భాషలు** — ఇంగ్లీష్, ఫ్రెంచ్, డచ్, హిందీ, తెలుగు, స్పానిష్, పోర్చుగీస్, జర్మన్, చైనీస్, జపనీస్ మరియు అరబిక్. మరిన్ని వస్తున్నాయి.
- **రెండు లెర్నింగ్ ట్రాక్‌లు** — సంభావిత అవగాహన కోసం *AI లెర్నింగ్ పాత్* (🌱 విత్తనాలు → 🌲 ఫారెస్ట్), మరియు ప్రయోగాత్మకంగా నిర్మించడం కోసం *క్రాఫ్ట్ ఇంజనీరింగ్ పాత్* (✏️ స్కెచ్ → 🏆 మాస్టర్ పీస్).
- **10 నిర్మాణాత్మక ప్రోగ్రామ్‌లు** — ప్రతి ఒక్కటి జాగ్రత్తగా క్రమబద్ధీకరించబడిన MDX పాఠాలు, ఇంటరాక్టివ్ అంశాలు మరియు పురోగతి ట్రాకింగ్‌తో ఉంటాయి.
- **ఇంటరాక్టివ్ ల్యాబ్** — న్యూరల్ నెట్‌వర్క్ ప్లేగ్రౌండ్, ప్రాంప్ట్ ల్యాబ్ మరియు సెంటిమెంట్ ఎనలైజర్‌తో సహా ఏడు ప్రయోగాలు — అన్నీ బ్రౌజర్‌లో రన్ అవుతాయి.
- **AI-ఆధారిత ఫీచర్లు** — Edu, మా అంతర్నిర్మిత చాట్‌బాట్, ఏదైనా ప్రోగ్రామ్ గురించిన ప్రశ్నలకు సమాధానాలు ఇస్తుంది. మాక్ ఇంటర్వ్యూ సిమ్యులేటర్ అభిప్రాయాలతో వాస్తవిక STAR-పద్ధతి ఇంటర్వ్యూలను నిర్వహిస్తుంది.
- **పూర్తి ప్రమాణపత్రాలు** — ప్రోగ్రామ్‌లోని అన్ని పాఠాలను ముగించి, వ్యక్తిగతీకరించిన PDF సర్టిఫికేట్‌ను డౌన్‌లోడ్ చేయండి.

## ఆర్కిటెక్చర్

మేము AI ఎడ్యుకాడెమీని ఆధునిక, కంపోజబుల్ ప్లాట్‌ఫారమ్‌గా నిర్మించాము:

```
┌─────────────────────────────────────────────┐
│              aieducademy.org                 │
│         Next.js 16 + React 19               │
│      ┌──────────┐  ┌──────────────┐         │
│      │  MDX      │  │  Interactive │         │
│      │  Lessons  │  │  Lab         │         │
│      └────┬─────┘  └──────┬───────┘         │
│           │               │                  │
│      ┌────▼───────────────▼──────┐           │

│      │  (Git Submodules per      │           │
│      │   program — own repos)    │           │
│      └───────────────────────────┘           │
│                                              │
│      ┌─────────┐  ┌──────────┐  ┌────────┐  │
│      │ Auth    │  │ Progress │  │ AI Chat│  │
│      │ NextAuth│  │ Neon PG  │  │ Gemini │  │
│      └─────────┘  └──────────┘  └────────┘  │
└──────────────────────────────────────────────┘
```

ప్రతి కోర్సు దాని స్వంత GitHub రిపోజిటరీలో నివసిస్తుంది, ప్లాట్‌ఫారమ్‌లోకి git సబ్‌మాడ్యూల్‌గా లాగబడుతుంది. దీని అర్థం:

- **కంటెంట్ రచయితలు** ప్లాట్‌ఫారమ్ కోడ్‌ను తాకకుండా పాఠాలు వ్రాయగలరు.
- **అనువాదకులు** ఏదైనా కోర్సు రెపోలో ఫోల్డర్‌ని సృష్టించడం ద్వారా భాషను జోడించగలరు.
- **ఏదైనా కంటెంట్ రెపో మార్పులు చేసినప్పుడు ప్లాట్‌ఫారమ్ స్వయంచాలకంగా పునర్నిర్మిస్తుంది**.

టెక్ స్టాక్: App Router + Turbopackతో Next.js 16, కఠినమైన మోడ్‌లో టైప్‌స్క్రిప్ట్, Tailwind CSS 4, i18n కోసం తదుపరి-intl, ప్రమాణీకరణ కోసం NextAuth v5 మరియు నిలకడ కోసం Neon Postgres. డిజైన్ సిస్టమ్ ఒక [ప్రత్యేక npm ప్యాకేజీ](https://www.npmjs.com/package/@aieducademy/ai-ui-library) ప్రచురించిన [స్టోరీబుక్](https://aieducademy.github.io/ai-ui-library/).

## డిఫాల్ట్‌గా ఓపెన్ సోర్స్

ప్లాట్‌ఫారమ్ కోడ్ యొక్క ప్రతి లైన్ MIT-లైసెన్స్ చేయబడింది మరియు [GitHub](https://github.com/ai-educademy)లో అందుబాటులో ఉంటుంది. విద్య మౌలిక సదుపాయాలు ప్రజా ప్రయోజనంగా ఉండాలని మేము నమ్ముతున్నాము.

మీరు:
- **స్వీయ-హోస్ట్** మీ పాఠశాల లేదా సంస్థ కోసం మొత్తం ప్లాట్‌ఫారమ్.
- **ఫోర్క్** ఒక కోర్సు రెపో మరియు మీ పాఠ్యాంశాలకు అనుగుణంగా.
- **సహకారం** అనువాదాలు, పాఠాలు, బగ్ పరిష్కారాలు లేదా ఫీచర్‌లు.

## తదుపరి ఏమిటి

మేము ఇప్పుడే ప్రారంభిస్తున్నాము. మా రోడ్‌మ్యాప్‌లో:

- 🌍 **మరిన్ని భాషలు** — కమ్యూనిటీ ఆధారిత అనువాద పోర్టల్ త్వరలో వస్తుంది.
- 🔌 **LMS ఇంటిగ్రేషన్** — విశ్వవిద్యాలయాలు మరియు పాఠశాలలకు LTI మద్దతు.
- 🧪 **ఇంటరాక్టివ్ కోడ్ వ్యాయామాలు** — తక్షణ అభిప్రాయంతో బ్రౌజర్‌లో కోడింగ్.
- 📱 **మొబైల్ యాప్** — AI విద్యను ఆఫ్‌లైన్‌లో తీసుకోవడం.
- 🎯 **వ్యక్తిగతీకరించిన అభ్యాస మార్గాలు** — మీ పురోగతి ఆధారంగా AI-ఆధారిత సిఫార్సులు.

## ప్రయత్నించండి

[aieducademy.org](https://aieducademy.org)కి వెళ్లి **AI విత్తనాలు**తో ప్రారంభించండి — సున్నా సాంకేతిక నేపథ్యం లేని వ్యక్తుల కోసం రూపొందించబడిన మా ప్రారంభ ట్రాక్. మీ మొదటి పాఠాన్ని పూర్తి చేయడానికి సుమారు 10 నిమిషాలు పడుతుంది.

మీకు ఇది ఉపయోగకరంగా అనిపిస్తే, [GitHub](https://github.com/ai-educademy/ai-platform) ⭐లో రెపోకు నక్షత్రం వేయండి — ఇది మరింత మంది వ్యక్తులు మమ్మల్ని కనుగొనడంలో సహాయపడుతుంది.
