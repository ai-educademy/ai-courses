# 你的面试工具包

木匠不会在没有工具的情况下出现在工作现场，你也不应该在没有工具的情况下出现在面试季节。无组织的求职和战略活动之间的区别在于其背后的**系统**。本课程将引导您了解像管理良好的项目一样进行面试准备所需的每个工具、模板和平台。

## 应用程序跟踪系统

如果您要申请三个以上的公司（您应该这样做），您需要一个系统来跟踪您在每个公司的情况。电子表格是最简单且最有效的选择。

### 推荐专栏

|专栏 |目的|
|--------|---------|
| **公司** |公司名称 |
| **角色** |具体职位名称和发布链接|
| **申请日期** |当您提交|
| **状态** |已申请/电话筛选/技术/现场/报价/拒绝|
| **下一步** |接下来会发生什么以及何时发生 |
| **招聘人员联系方式** |后续跟进的姓名和电子邮件 |
| **注释** |关键细节、Glassdoor 的面试技巧、内部联系人 |
| **后续日期** |如果您没有收到回复，何时查看 |

### 跟踪工具

- **Google Sheets / Excel** — 免费、灵活，您可以完全控制格式
- **概念** — 如果您更喜欢带有过滤器和不同布局的数据库样式视图
- **Trello / 看板** — 可视化管道：每一列都是一个阶段，每张卡都是一个应用程序
- **Huntr** — 带有浏览器扩展的专门构建的职位申请跟踪器

<Callout>同时向 5-10 家公司申请，而不是一次申请一家。并行应用程序可以让您在谈判中发挥作用，防止任何单一拒绝，并保持您的动力。您的跟踪电子表格使这一切变得易于管理。</Callout>

## 编码练习平台

并非所有练习平台都是一样的。根据您的目标和准备阶段进行选择。

### LeetCode
**最适合**：算法和数据结构实践、FAANG 式面试。

- **免费套餐**：通过社区解决方案访问 2,000 多个问题
- **高级版**（30 英镑/月）：公司标记的问题、频率排序和编辑解决方案
- **专业提示**：使用“Top Interview 150”列表作为结构化起点，而不是随机解决

### 网络代码
**最适合**：基于模式的学习、视觉解释。

- 150个核心问题的免费视频讲解
- 按模式组织问题（滑动窗口、两个指针、BFS/DFS）——最有效的学习方式
- NeetCode 150 可以说是目前最好的精选问题集

### 黑客排名
**最适合**：准备公司特定的在线评估。

- 许多公司使用HackerRank作为他们的技术筛选平台
- 熟悉界面可以减少实际评估过程中的摩擦
- 涵盖更广泛的范围：SQL、正则表达式和特定于语言的挑战以及算法

### 其他值得了解的平台

- **CodeSignal** — 被 Uber、Roblox 和 Brex 等公司用于在线评估
- **锻炼** — 非常适合通过指导练习学习新语言
- **AlgoExpert** — 包含 160 个精选问题的视频解释
- **欧拉计划** — 数学问题解决；小众但非常适合磨练逻辑思维

<FunFact>LeetCode 拥有超过 1500 万注册用户，托管超过 3000 个问题。然而，来自成功 FAANG 候选人的数据表明，您只需要深入理解 100-150 个精心挑选的问题即可涵盖 90% 面试中出现的模式。</FunFact>

## 模拟面试平台

单独练习是有用的，但它无法复制真实面试的社会压力。模拟面试平台弥补了这一差距。

### 普拉普
**最适合**：免费的点对点模拟面试。

- 你采访某人，然后他们采访你——双方都学习
- 提供跨编码、系统设计和行为的结构化问题
- 免费且无限制的会话
- 由于您的伴侣也是候选人，因此质量各不相同

### 采访.io
**最适合**：与顶级公司的工程师进行匿名练习。

- 面试官是谷歌、Facebook、亚马逊和类似公司的工程师
- 匿名——不会因为你的背景而产生偏见
- 每节课后的详细反馈
- 提供免费练习轮；辅导课程是有偿的

### 聚会和学习小组

- **Discord 服务器** — NeetCode Discord、Blind 75 学习小组等社区
- **本地聚会** — 在 Meetup.com 中搜索您所在城市的“编码面试准备”
- **大学校友网络** — 许多都开展非正式的模拟面试项目
- **付费辅导** — Exponent、Interviewing.io 辅导等服务，或 MentorCruise 等平台上的独立教练

<ThinkAboutIt>您最后一次在向他人解释您的思维过程时练习解决问题是什么时候？如果已经超过两周，请在本周安排一次模拟面试。社会压力部分是最难单独练习的。</ThinkAboutIt>

## 笔记模板

随着时间的推移，有组织的笔记复合。以下是最重要类别的模板。

### 公司研究模板
（公司研究策略课程中有详细介绍）

每个目标公司保留一份文档，其中包含以下部分：技术堆栈、文化、价值观、面试形式和您量身定制的故事。

### 故事库模板

准备 6-8 个涵盖常见行为主题的故事。使用这种格式：

```
## Story Title: [Short descriptive name]

### Situation
[2-3 sentences setting the context]

### Task
[What was your specific responsibility?]

### Action
[What did YOU do? Be specific about your individual contribution]

### Result
[Quantified outcome — metrics, impact, timeline]

### Tags
[leadership, conflict, failure, technical-challenge, teamwork, etc.]

### Company Fit
[Which company values does this story map to?]
```

### 面试汇报模板

每次访谈后，记录：

```
## [Company] - [Round] - [Date]

### Questions Asked
1. [Question 1] — My answer: [summary] — How it went: [well/okay/poorly]
2. [Question 2] — ...

### What Went Well
-

### What I Would Change
-

### Follow-up Study Topics
-

### Overall Feeling
[1-5 rating]
```

<Callout>你的故事库是一份活生生的文件。当您获得新经验时更新它，在模拟面试后完善您的表达方式，并在您意识到自己存在差距时添加新故事（例如，没有“失败”故事或没有“与经理意见不合”的故事）。</Callout>

## 远程面试的技术设置

远程采访现在已成为常态。糟糕的技术设置会产生摩擦，从而影响你的表现。

### 硬件清单

- **可靠的互联网** — 如果可能，使用有线以太网连接；有一个移动热点作为备份
- **网络摄像头位于视线高度** — 将书籍堆放在笔记本电脑下或使用外部网络摄像头
- **良好的音频** — 带麦克风的耳机每次都胜过笔记本电脑扬声器
- **外部显示器**（可选但有用）——一个用于编码环境的屏幕，一个用于注释的屏幕

### 软件清单

- **Zoom / Google Meet / Teams** — 安装并测试这三个；你永远不会提前知道是哪一个
- **浏览器** — 准备好 Chrome 和 Firefox；某些编码平台在其中一种平台上运行得比另一种更好
- **CoderPad / HackerRank / CodeSignal** — 创建免费帐户并解决每个帐户的一个练习问题以学习界面
- **IDE 备份** — 如果共享编辑器崩溃，请准备好屏幕共享本地 VS Code 或 IntelliJ

### 环境清单

- **安静的空间** — 降噪效果好；关上门更好
- **中性背景**——干净的墙壁或有品位的书架；避免分散注意力的背景
- **照明** — 面向窗户或使用台灯；避免背光
- **水和笔/纸** — 将它们放在触手可及的地方；你会需要它们
- **“请勿打扰”模式** - 在您的手机、笔记本电脑和任何智能设备上

## 日程安排和日历管理

当你积极地去多家公司面试时，日程安排本身就变成了一个项目。

### 最佳实践

- **在日历上设置面试准备时间** - 将其视为会议
- **按公司进行集群面试** — 尝试在同一周内对一家公司进行各轮面试，以维持背景
- **分开进行面试** — 避免在同一天安排两次技术面试；精神疲劳是真实存在的
- **安排你最擅长的时间** - 如果你是早起的人，请安排早上的面试时间
- **建立缓冲** - 每次采访前 30 分钟进行热身问题，采访结束后 15 分钟进行汇报

### 管理多个优惠

如果您有幸收到多个offer：

- **对招聘人员保持透明** — “我有另一份工作邀请，截止日期为 X；你能加快你的时间表吗？”
- **永远不要在收到录用通知时撒谎** - 招聘人员会互相交谈，而科技行业比你想象的要小
- **使用您的跟踪电子表格** — 添加包含薪酬、福利、开始日期和截止日期的“优惠详细信息”部分

### 为您的应用程序计时

理想的策略是**在同一个 1-2 周的窗口内启动所有应用程序**。这可以最大限度地提高您的报价大约在同一时间到达的机会，从而为您提供杠杆作用并避免在其他流程完成之前报价到期的压力。

<ThinkAboutIt>查看您当前的设置。如果你明天早上进行远程面试，你需要解决什么问题？你的网络可靠吗？您的网络摄像头处于视线水平吗？你有一个安静的空间吗？现在就解决这些后勤问题，而不是在面试前五分钟。</ThinkAboutIt>

## 完整的工具包清单

在开始面试活动之前，将此用作最终审核：

### 跟踪和组织
- [ ] 应用程序跟踪电子表格设置
- [ ] 公司研究模板已创建
- [ ] 故事库，准备了 6-8 个 STAR 故事
- [ ] 面试汇报模板已准备好

### 练习平台
- [ ] LeetCode / NeetCode 帐户已激活
- [ ] HackerRank / CodeSignal 帐户处于活动状态（用于在线评估）
- [ ] 至少安排一次模拟面试（Pramp 或 Interviewing.io）

### 技术设置
- [ ] 视频会议工具安装并测试
- [ ] 创建并测试编码平台帐户
- [ ] 互联网连接可靠，有备份计划
- [ ] 确定安静的采访空间

### 准备材料
- [ ] 制定每周里程碑的学习计划
- [ ] 系统设计参考资料加书签
- [ ] 带有映射故事的行为问题列表
- [ ] 为目标公司完成公司特定研究

## 行动项目

1. **立即设置您的跟踪电子表格** - 即使是一个简单的电子表格也胜过没有任何系统。
2. **在 LeetCode 和一个模拟面试平台上创建帐户** - 不要只是为它们添加书签；每解决一个问题。
3. **写下你的第一个 3 星故事** - 选择你最好的领导力、技术和失败故事。
4. **测试您的远程采访设置** - 与朋友进行视频通话，并询问有关您的音频、视频和背景的诚实反馈。
5. **安排您的第一次模拟面试** — Pramp 是免费的，您可以在 24 小时内预订一次。
