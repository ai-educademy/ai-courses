# 面接ツールキット

大工は道具を持たずに現場に来ることはありませんし、面接の季節に道具を持たずに現れるべきでもありません。無秩序な就職活動と戦略的なキャンペーンの違いは、その背後にある**システム**です。このレッスンでは、面接の準備を適切に管理されたプロジェクトのように実行するために必要なすべてのツール、テンプレート、プラットフォームについて説明します。

## アプリケーション追跡システム

3 つ以上の企業に応募している場合 (そうすべきです)、各企業での自分の立場を追跡するシステムが必要です。スプレッドシートは最もシンプルで効果的なオプションです。

### 推奨コラム

|コラム |目的 |
|--------|--------|
| **会社** |会社名 |
| **役割** |具体的な役職と投稿へのリンク |
| **適用日** |提出時 |
| **ステータス** |申請済み / 電話画面 / 技術 / オンサイト / オファー / 拒否 |
| **次のステップ** |次に何が起こるか、いつ起こるか |
| **採用担当者の連絡先** |フォローアップ用の名前とメールアドレス |
| **注意事項** |主要な詳細、Glassdoor からのインタビューのヒント、内部関係者との連絡先 |
| **フォローアップ日** |返事がない場合、いつチェックインすればよいですか |

### 追跡用ツール

- **Google スプレッドシート / Excel** — 無料で柔軟性があり、形式を完全に制御できます
- **Notion** — フィルターやさまざまなレイアウトを備えたデータベース スタイルのビューを希望する場合
- **Trello / Kanban ボード** — ビジュアル パイプライン: 各列はステージ、各カードはアプリケーションです
- **Huntr** — ブラウザ拡張機能を備えた専用のジョブ アプリケーション トラッカー

<Callout>1社ずつではなく、5～10社に同時に応募しましょう。並行して申請を行うことで、交渉に影響力を与え、一度の拒否から身を守り、勢いを維持することができます。追跡スプレッドシートを使用すると、これを管理しやすくなります。</Callout>

## コーディング実践プラットフォーム

すべての練習プラットフォームが同じように作られているわけではありません。目的や準備段階に合わせてお選びください。

### リートコード
**こんな方に最適**: アルゴリズムとデータ構造の演習、FAANG スタイルのインタビュー。

- **無料利用枠**: コミュニティ ソリューションによる 2,000 以上の問題へのアクセス
- **プレミアム** (£30/月): 企業タグ付きの問題、頻度ソート、および編集ソリューション
- **プロのヒント**: 無作為に解決するのではなく、構造化された出発点として「トップ インタビュー 150」リストを使用します。

### ニートコード
**最適な用途**: パターンベースの学習、視覚的な説明。

- 150 の主要な問題の無料ビデオ解説
- パターン別に整理された問題 (スライディング ウィンドウ、2 つのポインター、BFS/DFS) — 最も効果的な学習方法
- NeetCode 150 は、おそらく入手可能な中で最も精選された問題集です。

### ハッカーランク
**最適な用途**: 企業固有のオンライン評価の準備。

- 多くの企業が技術審査プラットフォームとして HackerRank を使用しています
- インターフェイスに慣れることで、実際の評価時の摩擦が軽減されます
- SQL、正規表現、アルゴリズムに加えて言語固有の課題など、より広範囲をカバーします

### 知っておく価値のあるその他のプラットフォーム

- **CodeSignal** — Uber、Roblox、Brex などの企業がオンライン評価に使用
- **演習** — 指導付きの演習を通じて新しい言語を学習するのに最適です
- **AlgoExpert** — 厳選された 160 個の問題セットを含むビデオ解説
- **プロジェクト オイラー** — 数学的問題解決。ニッチだが論理的思考を磨くのに最適

<FunFact>LeetCode には 1,500 万人を超える登録ユーザーがおり、3,000 を超える問題をホストしています。ただし、FAANG の合格者からのデータによると、面接の 90% に現れるパターンをカバーするには、厳選された 100 ～ 150 の問題を深く理解するだけで十分であることがわかります。</FunFact>

## 模擬面接プラットフォーム

一人で練習することは役に立ちますが、実際の面接のような社会的プレッシャーを再現することはできません。模擬面接プラットフォームはそのギャップを埋めます。

### 踏み台
**こんな方に最適**: 無料のピアツーピア模擬面接。

- あなたが誰かにインタビューし、次に彼らもあなたにインタビューします - 双方が学びます
- コーディング、システム設計、行動に関する構造化された質問が提供されます
- 無料かつ無制限のセッション
- パートナーも候補者であるため、品質は異なります

### インタビュー.io
**こんな方に最適**: 一流企業のエンジニアによる匿名の練習。

- 面接官は Google、Facebook、Amazon などの企業のエンジニアです
- 匿名 — あなたの経歴に基づく偏見はありません
- 各セッション後の詳細なフィードバック
- 無料の練習ラウンドが利用可能;コーチングセッションは有料です

### ミートアップと勉強会

- **Discord サーバー** — NeetCode Discord、Blind 75 研究グループなどのコミュニティ
- **ローカルミートアップ** — お住まいの地域で Meetup.com で「コーディング面接準備」を検索してください
- **大学同窓会ネットワーク** - 多くが非公式の模擬面接プログラムを実施しています
- **有料コーチング** — Exponent、Interviewing.io コーチングなどのサービス、または MentorCruise などのプラットフォームでの独立したコーチング

<ThinkAboutIt>自分の思考プロセスを他の人に説明しながら問題を解決する練習をしたのはいつですか? 2 週間以上経過している場合は、今週模擬面接を予定してください。社会的プレッシャーの要素は、単独で実践するのが最も困難です。</ThinkAboutIt>

## メモ取りテンプレート

整理されたメモは時間の経過とともに増えていきます。最も重要なカテゴリのテンプレートを次に示します。

### 企業調査テンプレート
(企業研究戦略のレッスンで詳しく説明します)

技術スタック、文化、価値観、インタビュー形式、カスタマイズされたストーリーなどのセクションを含む文書を対象企業ごとに 1 つ作成します。

### ストーリーバンクテンプレート

一般的な行動テーマを取り上げたストーリーを 6 ～ 8 つ用意します。次の形式を使用します。

```
## Story Title: [Short descriptive name]

### Situation
[2-3 sentences setting the context]

### Task
[What was your specific responsibility?]

### Action
[What did YOU do? Be specific about your individual contribution]

### Result
[Quantified outcome — metrics, impact, timeline]

### Tags
[leadership, conflict, failure, technical-challenge, teamwork, etc.]

### Company Fit
[Which company values does this story map to?]
```

### 面接報告書のテンプレート

すべてのインタビューの後、次のことを記録します。

```
## [Company] - [Round] - [Date]

### Questions Asked
1. [Question 1] — My answer: [summary] — How it went: [well/okay/poorly]
2. [Question 2] — ...

### What Went Well
-

### What I Would Change
-

### Follow-up Study Topics
-

### Overall Feeling
[1-5 rating]
```

<Callout>あなたのストーリーバンクは生きた文書です。新しい経験を積むたびに更新し、模擬面接後の話し方を磨き、ギャップがあることに気づいたら新しいストーリーを追加します (例: 「失敗」のストーリーがない、または「マネージャーとの意見の相違」のストーリーがない)。</Callout>

## リモート面接のための技術セットアップ

リモート面接が主流になりました。技術的なセットアップが不十分だと摩擦が生じ、パフォーマンスが妨げられます。

### ハードウェアチェックリスト

- **信頼性の高いインターネット** - 可能であれば有線イーサネット接続を使用してください。バックアップとしてモバイルホットスポットを用意する
- **目の高さにウェブカメラ** — ラップトップの下に本を重ねるか、外部ウェブカメラを使用します
- **優れたオーディオ** — マイク付きヘッドセットは常にラップトップのスピーカーよりも優れています
- **外部モニター** (オプションですが便利です) — コーディング環境用に 1 画面、メモ用に 1 画面

### ソフトウェアチェックリスト

- **Zoom / Google Meet / Teams** — 3 つすべてをインストールしてテストします。どちらが事前にわかるとは限りません
- **ブラウザ** — Chrome と Firefox を準備しておきます。一部のコーディング プラットフォームは、一方の方が他方よりもうまく動作します。
- **CoderPad / HackerRank / CodeSignal** — 無料アカウントを作成し、それぞれで 1 つの練習問題を解いてインターフェースを学習します
- **IDE バックアップ** - 共有エディターがクラッシュした場合は、ローカルの VS Code または IntelliJ を画面共有する準備をしてください。

### 環境チェックリスト

- **静かな空間** — ノイズキャンセリングは優れています。ドアは閉めた方が良い
- **ニュートラルな背景** — きれいな壁または上品な本棚。気を散らす背景を避ける
- **照明** — 窓に面するか、電気スタンドを使用します。逆光を避ける
- **水とペン/紙** — 手の届くところに用意してください。あなたにはそれらが必要になるでしょう
- **「おやすみモード」** — 携帯電話、ラップトップ、その他のスマート デバイスで

## スケジュールとカレンダーの管理

複数の企業で積極的に面接を行っている場合、スケジュールを立てること自体がプロジェクトになります。

### ベストプラクティス

- **面接の準備時間をカレンダーでブロック** — 会議のように扱います
- **企業ごとのクラスター面接** — 文脈を維持するために、同じ週内に 1 つの企業ですべての面接を行うようにしてください。
- **面接の間隔を空ける** — 同じ日に 2 つの技術面接をスケジュールすることは避けてください。精神的な疲労は本物です
- **最強の時間をスケジュールする** — あなたが朝型の場合は、午前中の面接枠を取りましょう
- **バッファを組み込む** — 各面接の 30 分前にウォーミングアップの問題を行い、その後 15 分で報告会を行います

### 複数のオファーの管理

幸運にも複数のオファーを受け取った場合:

- **採用担当者に対して透明性を保つ** — 「期限が X の別のオファーがあります。スケジュールを早めてもらえますか?」
- **内定があることについて決して嘘をつかないでください** — 採用担当者は互いに話し合っており、テクノロジー業界はあなたが思っているよりも小さいです
- **追跡スプレッドシートを使用** — 報酬、福利厚生、開始日、期限を記載した「オファーの詳細」セクションを追加します。

### アプリケーションのタイミングを調整する

理想的な戦略は、*すべてのアプリケーションを同じ 1 ～ 2 週間以内に開始する**ことです。これにより、オファーがほぼ同時に到着する可能性が最大化され、他のプロセスが完了する前にオファーが期限切れになるというプレッシャーを回避し、活用することができます。

<ThinkAboutIt>現在の設定を見てください。明日の朝にリモート面接がある場合、何を修正する必要がありますか?あなたのインターネットは信頼できますか?ウェブカメラは目の高さにありますか?静かな空間はありますか？面接の 5 分前に、今すぐこれらの手順を修正してください。</ThinkAboutIt>

## 完全なツールキットのチェックリスト

面接キャンペーンを開始する前の最終監査としてこれを使用してください。

### 追跡と組織化
- [ ] アプリケーション追跡スプレッドシートのセットアップ
- [ ] 企業調査テンプレートを作成しました
- [ ] 6〜8のSTARストーリーが用意されたストーリーバンク
- [ ] 面接報告書テンプレートが完成しました

### 練習プラットフォーム
- [ ] LeetCode / NeetCode アカウントがアクティブです
- [ ] HackerRank / CodeSignal アカウントがアクティブ (オンライン評価用)
- [ ] 少なくとも 1 つの模擬面接が予定されています (Pramp またはinterviewing.io)

### 技術的なセットアップ
- [ ] ビデオ会議ツールがインストールされ、テストされています
- [ ] コーディング プラットフォーム アカウントが作成され、テストされました
- [ ] バックアッププランで安心のインターネット接続
- [ ] 静かな面接スペースが特定されました

### 準備資料
- [ ] 毎週のマイルストーンを作成した学習計画
- [ ] システム設計参考資料をブックマークしました
- [ ] ストーリーがマッピングされた行動に関する質問リスト
- [ ] 対象企業に対する企業固有の調査が完了しました

## アクションアイテム

1. **今すぐ追跡スプレッドシートをセットアップしてください** — たとえ簡単なスプレッドシートであっても、どのシステムにも勝るものはありません。
2. **LeetCode と 1 つの模擬面接プラットフォームでアカウントを作成します** — 単にブックマークするだけではありません。それぞれ1つずつ問題を解きます。
3. **最初の 3 つ星のストーリーを作成します** — 最高のリーダーシップ、技術、失敗のストーリーを選択します。
4. **リモート インタビューの設定をテストします** — 友人とビデオ通話を行い、音声、ビデオ、背景についての正直なフィードバックを求めます。
5. **最初の模擬面接をスケジュールする** — Pramp は無料で、24 時間以内に予約できます。
