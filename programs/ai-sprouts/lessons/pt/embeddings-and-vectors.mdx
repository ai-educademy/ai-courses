# Embeddings - Como a IA entende o significado

Após a tokenização, cada token é apenas um número – um índice em um vocabulário. Mas o índice 4.821 não diz nada ao modelo sobre o *significado*. Como a IA sabe que “rei” e “rainha” estão relacionados, ou que “banco” pode significar a margem de um rio ou uma instituição financeira? A resposta é **incorporações**.

## O problema com codificação One-Hot

A abordagem ingênua representa cada palavra como um vetor com um `1` e milhares de `0`s. "Gato" pode ser `[0, 0, 1, 0, ..., 0]` e "cachorro" `[0, 0, 0, 1, ..., 0]`.

Isso tem duas falhas fatais:

- **Sem semelhança:** "Gato" e "cachorro" estão igualmente distantes um do outro como "gato" e "democracia". A codificação captura zero informação semântica.
- **Tamanho enorme:** Com um vocabulário de 50.000 palavras, cada palavra precisa de um vetor de 50.000 dimensões. Extremamente ineficiente.

## Incorporações de palavras - Significado como geometria

Uma **incorporação** mapeia cada token para um vetor denso de, digamos, 256 ou 768 dimensões. Ao contrário dos vetores one-hot, essas dimensões são aprendidas durante o treinamento e codificam o significado.

Palavras usadas em contextos semelhantes acabam juntas neste espaço. “Filhote de cachorro” pousa perto de “gatinho”. “Londres” pousa perto de “Paris”. A geometria do espaço *é* o significado.

## Word2Vec - Rei − Homem + Mulher = Rainha

O artigo **Word2Vec** de 2013 mostrou algo notável. Treinados em grandes corpora de texto, os vetores aprendidos exibem relações aritméticas:

> `vector("king") − vector("man") + vector("woman") ≈ vector("queen")`

A direção de “homem” para “mulher” capta o conceito de gênero. Adicioná-lo a “rei” move-se para “rainha”. Isto não é programado – emerge de padrões de linguagem.

Outros exemplos: `Paris − France + Italy ≈ Rome`, `bigger − big + small ≈ smaller`.

<FunFact>Word2Vec foi criado por Tomáš Mikolov no Google em 2013. O artigo tem mais de 40.000 citações e é considerado um dos artigos de PNL mais influentes já publicados. Demonstrou que redes neurais simples treinadas em texto bruto poderiam aprender relações semânticas surpreendentes.
</FunFact>

## Incorporando Dimensões

Os modelos modernos usam diferentes tamanhos de incorporação:

| Modelo | Dimensões de incorporação |
|-------|---------------------|
| Word2Vec | 100–300 |
| BERT | 768 |
| GPT-3 | 12.288 |
| OpenAI text-embedding-3-large | 3.072 |

Mais dimensões capturam distinções mais precisas, mas exigem mais memória e computação. Pense nisso como descrever uma pessoa: três dimensões (altura, peso, idade) fornecem um esboço; 768 dimensões pintam um retrato detalhado.

## De palavras a frases

Os embeddings de palavras representam palavras individuais, mas muitas vezes precisamos comparar frases ou documentos inteiros. **Embeddings de frases** (de modelos como Sentence-BERT ou API de incorporação do OpenAI) compactam uma passagem inteira em um único vetor.

"Como faço para redefinir minha senha?" e "Esqueci minhas credenciais de login" teriam incorporações de frases muito semelhantes, embora quase não compartilhem palavras. A incorporação captura a *intenção*, não apenas o vocabulário.

## Medindo Similaridade - Similaridade de Cosseno

Para comparar dois embeddings, usamos **semelhança de cosseno** - o cosseno do ângulo entre dois vetores. Varia de −1 (oposto) a +1 (direção idêntica).

- “Feliz” e “alegre”: cosseno ≈ 0,85 (muito semelhante).
- “Happy” e “table”: cosseno ≈ 0,10 (não relacionado).
- "Amor" e "ódio": o cosseno pode ser ≈ 0,40 (relacionado, mas oposto).

A similaridade de cossenos ignora a magnitude do vetor, concentrando-se puramente na direção - que é onde reside o significado.

</ThinkAboutIt>

## Bancos de dados de vetores - Pesquisa por significado

Um **banco de dados vetorial** armazena milhões de embeddings e recupera os mais semelhantes com extrema rapidez. Em vez de correspondência de palavras-chave ("encontrar documentos contendo 'aprendizado de máquina'"), você pesquisa por *significado* ("encontrar documentos sobre educação em IA").

Bancos de dados de vetores populares incluem:

- **Pinecone** - totalmente gerenciado, escalável sem esforço.
- **Weaviate** - código aberto com pesquisa híbrida (vetores + palavras-chave).
- **ChromaDB** - leve, ótimo para prototipagem.
- **pgvector** - adiciona pesquisa vetorial ao PostgreSQL.

Esses bancos de dados usam algoritmos como **HNSW** (Hierarchical Navigable Small World) para pesquisar bilhões de vetores em milissegundos.

## RAG - Geração Aumentada de Recuperação

**RAG** ​​é um dos padrões mais importantes da IA ​​moderna. Combina pesquisa vetorial com modelos de linguagem:

1. **Incorpore** seus documentos e armazene-os em um banco de dados vetorial.
2. Quando um usuário fizer uma pergunta, **incorpore** a consulta.
3. **Recupere** os pedaços de documentos mais semelhantes por meio de pesquisa vetorial.
4. **Alimente** esses pedaços ao modelo de linguagem como contexto.
5. O modelo **gera** uma resposta baseada em seus dados.

O RAG permite que os modelos de linguagem respondam a perguntas sobre *seus* dados específicos - documentos da empresa, catálogos de produtos, documentos de pesquisa - sem necessidade de treinamento adicional. Reduz drasticamente as alucinações porque o modelo tem fontes reais para referência.

## Aplicações Práticas

Os embeddings alimentam inúmeros sistemas do mundo real:

- **Pesquisa semântica** - encontre resultados relevantes independentemente do texto exato.
- **Recomendações** - "usuários que gostaram disso também gostaram..." via incorporação de similaridade.
- **Clustering** - agrupe tickets de suporte, análises ou documentos semelhantes automaticamente.
- **Detecção de anomalias** - detecta valores discrepantes que estão longe de qualquer cluster.
- **Detecção de duplicatas** – encontre conteúdo quase idêntico em grandes corpora.

<FunFact>O Spotify usa incorporações de áudio para recomendar músicas. Cada faixa é incorporada com base em suas características acústicas, e as recomendações vêm da localização de vetores próximos - músicas que "soam semelhantes" no espaço incorporado.
</FunFact>

<ThinkAboutIt>Se você incorporasse todos os produtos em uma loja on-line, como poderia construir um sistema de recomendação que diz “os clientes que visualizaram este item também podem gostar...” sem depender do histórico de compras?
</ThinkAboutIt>

## Principais conclusões

- **Incorporações** são representações vetoriais densas onde o significado se torna geometria.
- Conceitos semelhantes agrupam-se; relacionamentos aparecem como direções.
- **Semelhança de cosseno** mede a proximidade de dois significados.
- **Bancos de dados vetoriais** permitem a pesquisa por significado em grande escala.
- **RAG** ​​combina pesquisa vetorial com modelos de linguagem para responder perguntas a partir de seus próprios dados.
