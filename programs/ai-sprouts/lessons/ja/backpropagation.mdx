# バックプロパゲーション - 学習のエンジン

前のレッスンでは、ニューラル ネットワークには重みがあり、トレーニングによってそれらの重みが調整されることを見ました。しかし、ネットワークはどの重みをどのくらい変更すべきかを*どのように*知るのでしょうか?答えは **バックプロパゲーション** です。これは現代の深層学習において最も重要なアルゴリズムです。

Andrej Karpathy 氏は、これを「ニューラル ネットワークについて理解するのが最も重要なこと」と呼んでいます。その理由を見てみましょう。

## フォワードパスの簡単な要約

**順方向パス**中、データはネットワーク内を左から右に流れます。

1. 入力に重みを乗算し、合計します。
2. バイアスを追加します。
3. 活性化関数 (ReLU など) が適用されます。
4. 出力は次の層にフィードされ、最終的な予測が現れるまで繰り返されます。

次に、**損失関数** (次のレッスンで説明します) を使用して、予測が真の答えと比較されます。損失は​​次のような単一の数字です: *「これがあなたがどれほど間違っているかです。」*

## 重要な洞察 - 責任の割り当て

ケーキを焼いたと想像してみてください、そしてそれはひどい味です。 5つの材料を使いました。問題は、*どの成分がその不味さに最も寄与しているのか、そしてどの程度影響しているのかということです。*

逆伝播は、ニューラル ネットワークに関するこの質問に正確に答えます。 「この重みを少し微調整すると、損失はどのくらい変化しますか?」と尋ねることによって、すべての重みに**責任**を割り当てます。

その変化率は **勾配** と呼ばれ、これは微積分、特に **微分** から得られます。

<FunFact>「AI のゴッドファーザー」の 1 人であるジェフリー・ヒントンは、バックプロパゲーションがディープラーニングを実用化した重要なアイデアであると述べています。これがなければ、数百万のパラメーターを使用してネットワークをトレーニングすることは計算上不可能になります。
</FunFact>

## チェーンルール - すべてを支配するための 1 つのアイデア

ニューラル ネットワークは、単純な操作を組み合わせたチェーンです。微積分の**連鎖規則**は、合成された関数を区別する方法を教えてくれます。

> `y = f(g(x))`の場合は、`dy/dx = f'(g(x)) × g'(x)`。

**日常のたとえ:** あなたは車でお店に行きます。速度はアクセルをどれだけ強く踏むかによって決まります。アクセル開度は交通量によって異なります。交通状況が速度に与える影響を知るには、*(アクセルを押すごとの速度)* × *(交通状況ごとのアクセルを押す)*を掛けます。それが連鎖ルール、つまり連鎖に沿って局所的な変化率を乗算するというものです。

<FunFact>バックプロパゲーションは、Rumelhart、Hinton、Williams による 1986 年の画期的な論文で普及しましたが、逆モード自動微分の中核となるアイデアは 1960 年代に遡ります。
</FunFact>

## 計算グラフ - 数学の視覚化

PyTorch のような最新のフレームワークは、フォワード パス中に **計算グラフ** を構築します。すべての操作 (加算、乗算、ReLU) がノードになります。次に、バックプロパゲーションはこのグラフを**逆方向**に実行し、各ノードで連鎖ルールを適用して勾配を計算します。

それを河川システムのように考えてください。損失は​​最後に海です。 Backprop は、上流のすべての支流をトレースして、各ソース (重み) が最終的な流れにどれだけ寄与したかを確認します。

### 小さな実際の例

`L = (w × x - y)²` に `w = 2`、`x = 3`、`y = 10` があるとします。

1. **進む:** `w × x = 6`、次に `6 - 10 = -4`、次に `(-4)² = 16`。損失 = 16。
2. **後方:** `dL/d(diff) = 2 × (-4) = -8`、次に `d(diff)/d(wx) = 1`、つまり `dL/d(wx) = -8`。
3. 最後に、`d(wx)/dw = x = 3`なので、**`dL/dw = -8 × 3 = -24`** となります。

−24 の勾配は、*`w`を増やすと損失が急速に減少することを示しています。* これはまさに改善する必要がある信号です。

## レイヤーを通るグラデーション フロー

深いネットワークでは、勾配は多くの層を通過する必要があります。各レイヤーは、勾配にその局所導関数を乗算します。これにより、次の 2 つの危険な故障モードが発生します。

### 消えるグラデーション

局所導関数が小さい場合 (たとえば、シグモイド関数が 0 または 1 付近で飽和する場合)、乗算を繰り返すと勾配がゼロに向かって縮小します。初期の層はほとんど学習せず、信号をほとんど受信しません。これは初期のディープネットワークを悩ませていました。

### 爆発的なグラデーション

局所導関数が大きい場合、勾配は指数関数的に増加します。重みが大量の更新を受信すると、ネットワークが不安定になり、NaN 値が生成されます。

<ThinkAboutIt>ReLU の導関数は 0 または 1 のいずれかで、アクティブなときに勾配を縮小することはありません。この単純な特性が、深いネットワークのトレーニングにとって革命的であったのはなぜでしょうか?
</ThinkAboutIt>

**最新のソリューションには次のものが含まれます:**
- **ReLU アクティベーション** - 正の入力の導関数は 1 であり、縮小を回避します。
- **残留接続 (スキップ接続)** - グラデーションにレイヤーをバイパスする高速道路を与えます。
- **バッチ正規化** - 値を健全な範囲に保ちます。
- **グラデーション クリッピング** - 爆発を防ぐためにグラデーションをキャップします。

## 重みが実際にどのように更新されるか

バックプロップがすべての勾配を計算したら、**オプティマイザー** (次のレッスン) が各重みを更新します。

```
w_new = w_old - learning_rate × gradient
```

学習率はステップ サイズを制御します。大きすぎるとオーバーシュートしてしまいます。小さすぎるとトレーニングに時間がかかります。グラデーションは方向を示します。学習率は、どのくらいの距離を歩けばよいかを示します。

## バックプロップが重要な理由

ChatGPT が次の単語の予測を改善するたび、自動運転車がステアリングを改良するたびに、バックプロパゲーションが根底で実行されています。これは、**間違いから学ぶ** を数学的に正確にするアルゴリズムです。

バックプロップがなければ、数百万、または数十億のパラメーターを使用してネットワークをトレーニングする効率的な方法はありません。

## 重要なポイント

- **バックプロパゲーション** は、計算グラフを逆にたどることによって勾配を計算します。
- **チェーン ルール** は、各パスに沿ってローカル導関数を乗算します。
- **勾配消失**は学習を遅らせます。 **爆発的な勾配**はそれを不安定にします。
- 最新のトリック (ReLU、スキップ接続、グラデーション クリッピング) により、グラデーション フローを健全に保ちます。
- バックプロップ + オプティマイザー = すべての最新の深層学習の学習エンジン。
