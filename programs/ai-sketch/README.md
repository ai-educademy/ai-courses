# ✏️ AI Sketch

Engineering foundations for AI builders

Part of [AI Educademy](https://aieducademy.org).

[Start learning](https://aieducademy.org/programs/ai-sketch) | [Platform repo](https://github.com/ai-educademy/ai-platform) | [UI library](https://github.com/ai-educademy/ai-ui-library)

## Overview

Strengthen the programming, data structures, testing, and complexity fundamentals that make AI systems understandable, efficient, and maintainable.

This public repo contains the free first lesson and supporting public content for this programme.

## Programme facts

| Field | Value |
|-------|-------|
| Track | Craft and Engineering |
| Level | 1 |
| Lessons | 10 |
| Estimated study time | 10 hours |
| Audience | Developers beginning AI engineering or interview preparation |
| Prerequisites | Basic programming in Python, JavaScript, Java, or another language |

## Topics

- Complexity and trade-offs
- Core data structures
- Searching, sorting, and graphs
- Testing and debugging
- Data pipelines and API boundaries

## Outcomes

- Choose data structures deliberately
- Explain time and space trade-offs
- Write testable solutions under constraints
- Connect algorithms to real AI application workloads
