## 関係のあるデータ

これまで、データを行単位で見てきました。配列、リンク リスト、スタック、キューはすべて、項目を順番に並べたものです。しかし、現実の世界は直線的ではありません。家系図が枝分かれしていきます。ソーシャル ネットワークはウェブを形成します。道路地図は相互接続されたルートを作成します。

**ツリー** と **グラフ** はこれらの関係をキャプチャし、AI の最も強力な技術の中心となります。

## ツリー - 階層データ

**ツリー**は、各項目 (**ノード**と呼ばれる) が子ノードを持つことができ、階層を形成できる構造です。最上位には **ルート** と呼ばれる特別なノードが 1 つあり、子のないノードは **葉** と呼ばれます。

```
         CEO
        /    \
      CTO    CFO
     /   \      \
   Dev1  Dev2   Accountant
```

### 木はどこにでもあります

- **ファイル システム**: フォルダーには、ファイルを含むサブフォルダー (ツリー) が含まれます。
- **HTML/DOM**: すべての Web ページは、ネストされた要素のツリーです。
- **組織図**: マネージャーにはレポートがあり、マネージャーには独自のレポートがある場合があります。
- **JSON データ**: JSON の入れ子構造は基本的にツリーです。

### 二分木

**バイナリ ツリー** では、各ノードが最大 2 つの子 (左の子と右の子) に制限されます。この単純な制約により、強力なアルゴリズムが可能になります。

```
        8
       / \
      3   10
     / \    \
    1   6    14
```

### 二分探索木 (BST)

**二分探索ツリー** には 1 つのルールが追加されます。つまり、すべてのノードについて、左側のサブツリーのすべての値が小さく、右側のサブツリーのすべての値が大きくなります。

これにより、検索が高速になります。各ノードで、左に進むか右に進むかがわかります。

```
Find 6 in the BST above:
  Start at 8 → 6 < 8, go left
  At 3 → 6 > 3, go right
  At 6 → Found it!
```

**時間計算量**: バランスのとれたツリーの場合は O(log n) - ソートされた配列の二分探索と同じ対数魔法です。

## グラフ - すべてがつながっている

**グラフ** は、階層制約を削除することでツリーを一般化します。これは **ノード** (頂点とも呼ばれる) と **エッジ** (ノード間の接続) で構成されます。エッジは次のとおりです。

- **有向** (一方向: A → B) または **無向** (双方向: A ↔ B)
- **重み付け** (各エッジにはコスト/距離があります) または **重み付けなし**

```
Social network (undirected):
  Alice - Bob - Charlie
    \       |
     Diana - Eve

Road map (weighted, directed):
  London →(2h)→ Birmingham →(1.5h)→ Manchester
```

### グラフはどこにでもあります

- **ソーシャル ネットワーク**: 人々はノードです。友情は縁だ。
- **インターネット**: Web ページはノードです。ハイパーリンクはエッジです。
- **道路地図**: 交差点はノードです。道路は距離の重みをもつエッジです。
- **レコメンデーション システム**: ユーザーと製品はノードです。インタラクションはエッジです。

<FunFact>Facebook のソーシャル グラフには、30 億を超えるノード (ユーザー) と数千億のエッジ (友人関係) が含まれています。グラフ アルゴリズムは、ニュース フィード、友人の提案、広告のターゲティングを決定します。これらはすべて、これまでに構築された最大のグラフの 1 つで実行されます。
</FunFact>

## AI が木をどのように使用するか

### ディシジョン ツリー

最も解釈しやすい AI モデルの 1 つは **デシジョン ツリー** です。データを分類するために一連の「はい/いいえ」の質問をします。

```
Is temperature > 30°C?
├── Yes: Is humidity > 70%?
│   ├── Yes: "Don't play tennis"
│   └── No: "Play tennis"
└── No: Is it windy?
    ├── Yes: "Don't play tennis"
    └── No: "Play tennis"
```

デシジョン ツリーが人気があるのは、人間がそれを読んで理解できるためです。これは、説明可能性が重要となる医療、金融、法律 AI において非常に重要です。

<ThinkAboutIt>病院は AI を使用して患者のリスクを予測します。規制当局はAIにその決定を説明するよう要求する。たとえニューラル ネットワークの方がわずかに正確であるとしても、なぜここでディープ ニューラル ネットワークよりもデシジョン ツリーが好まれるのでしょうか?
</ThinkAboutIt>

### ランダムフォレスト

**ランダム フォレスト**は数百のデシジョン ツリーを構築し、それぞれがわずかに異なるデータのサブセットでトレーニングされ、投票を受けます。このアンサンブル アプローチは、単一のツリーよりも正確かつ堅牢であり、現在でも業界で最も広く使用されている AI 技術の 1 つです。

## AI によるグラフの使用方法

### ナレッジグラフ

**ナレッジ グラフ** は、事実をエンティティ間の関係として保存します。

```
(London) --[capital_of]--> (United Kingdom)
(London) --[located_in]--> (England)
(Big Ben) --[located_in]--> (London)
```

Google のナレッジ グラフは、検索結果に表示される情報パネルを強化します。 「ビッグ ベン」を検索すると、グラフがイギリスのロンドンと関連するランドマークを結び付けます。

### 推奨グラフ

Netflix、Spotify、Amazon はユーザーとアイテムをグラフとしてモデル化します。ユーザー A と B が両方ともアイテム X と Y が好きで、ユーザー A もアイテム Z が好きだった場合、グラフはユーザー B に Z を提案します。これは、グラフ構造を利用した**協調フィルタリング**です。

## トラバーサル - ツリーとグラフの中を歩く

### 深さ優先検索 (DFS)

DFS は、後戻りする前に 1 つのパスに沿って可能な限り探索します。行き止まりに突き当たるまで常に左端に曲がり、その後後戻りすることで迷路を探索するようなものだと考えてください。

```
        A
       / \
      B   C
     / \   \
    D   E   F

DFS order: A → B → D → E → C → F
```

DFS は **スタック** を使用します (自然に再帰経由、または明示的に)。以下のような方に最適です:
- 迷路やパズルを解く
- グラフ内のサイクルの検出
- トポロジーソート (依存関係のあるタスクの順序付け)

### 幅優先検索 (BFS)

BFS は、より深く移動する前に、現在の深さですべての近隣を探索します。池に落とした石から広がる波紋のようなものだと考えてください。

```
        A
       / \
      B   C
     / \   \
    D   E   F

BFS order: A → B → C → D → E → F
```

BFS は **キュー** を使用します。以下のような方に最適です:
- 重み付けされていないグラフでの最短パスの検索
- ソーシャルネットワーク分析（分離度）
- Web クローリング (ページをレベルごとに訪問)

<Callout>前のレッスンのスタックとキューがツリーとグラフのトラバーサルにどのように接続されているかに注目してください。 DFS はスタックを使用します。 BFS はキューを使用します。データ構造は相互に構築されます。だからこそ、データ構造を順番に学習することが重要です。
</Callout>

</ThinkAboutIt>

<FunFact>Google の PageRank アルゴリズム (Google を支配的なものにした最初の画期的な技術) は、Web をグラフとしてモデル化します。各 Web ページはノードであり、各ハイパーリンクは有向エッジであり、ページの重要性は、そのページにリンクされている重要なページの数によって決まります。これは基本的にグラフ上のランダムウォークです。
</FunFact>

## 重要なポイント

- **ツリー** モデルの階層データ - ファイル システム、HTML、および AI デシジョン ツリーはすべてツリー構造を使用します。
- **二分探索ツリー** は、ソートされた階層を維持することで O(log n) ルックアップを可能にします。
- **グラフ** は、ソーシャル ネットワーク、ナレッジ ベース、推奨エンジンなどの相互接続されたデータをモデル化します。
- **DFS** (スタックベース) は深くなります。 **BFS*​​ (キューベース) は広範囲にわたり、PageRank などのコア AI アルゴリズムと推奨エンジンの両方を強化します。
