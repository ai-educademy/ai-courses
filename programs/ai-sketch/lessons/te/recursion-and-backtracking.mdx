## రికర్షన్ పునాదులు

రికర్సివ్ ఫంక్షన్ **base కేసు** చేరుకునే వరకు సమస్య యొక్క **చిన్న** రూపంతో తనను తాను కాల్ చేసుకుంటుంది.

ప్రతి రికర్షన్ కి రెండు విషయాలు కావాలి:
1. **Base కేసు** - నేరుగా return చేసే సరళమైన ఇన్‌పుట్.
2. **రికర్సివ్ కేసు** - సమస్యను విభజించి తనను తాను కాల్ చేసుకోవడం.

```python
def factorial(n):
    if n <= 1:        # base case
        return 1
    return n * factorial(n - 1)  # recursive case
```

## కాల్ స్టాక్ - దృశ్యీకరణ

ప్రతి రికర్సివ్ కాల్ కాల్ స్టాక్ పైకి frame పుష్ చేస్తుంది. Base కేసు return అయినప్పుడు, frames రివర్స్ క్రమంలో పాప్ అవుతాయి.

```
factorial(4)
  → factorial(3)
    → factorial(2)
      → factorial(1) → 1 return చేస్తుంది
    ← 2 return చేస్తుంది
  ← 6 return చేస్తుంది
← 24 return చేస్తుంది
```

Base కేసు లేకపోతే, స్టాక్ ఓవర్‌ఫ్లో అవుతుంది. Python default రికర్షన్ పరిమితి 1,000 frames.

<FunFact>Python 1,000 రికర్షన్ పరిమితి ఉద్దేశపూర్వకంగా conservative. sys.setrecursionlimit() తో పెంచవచ్చు, కానీ deep రికర్షన్ కి iterative solutions సాధారణంగా ఇష్టపడతారు.</FunFact>

## Fibonacci - క్లాసిక్ ఉచ్చు

Naïve రికర్సివ్ Fibonacci O(2ⁿ) ఎందుకంటే ఇది అదే sub-problems ను మళ్ళీ మళ్ళీ గణించండి చేస్తుంది. మెమోయిజేషన్ దీన్ని O(n) సమయం మరియు అంతరిక్షంలో పరిష్కరిస్తుంది.

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)
```

## బ్యాక్‌ట్రాకింగ్ - అన్నీ ప్రయత్నించు, తర్వాత రద్దు చేయి

బ్యాక్‌ట్రాకింగ్ అనేది twist తో రికర్షన్: మీరు **ఎంపిక చేసి**, రికర్స్ చేసి, తదుపరి option ప్రయత్నించే ముందు **ఎంపికను రద్దు చేస్తారు**. మేజ్ అన్వేషించు చేయడం అనుకోండి - ముందుకు నడవండి, dead end తగిలితే వెనక్కి, తదుపరి పాత్ ప్రయత్నించండి.

### బ్యాక్‌ట్రాకింగ్ Template

```python
def backtrack(state, choices):
    if is_solution(state):
        result.append(state.copy())
        return
    for choice in choices:
        if is_valid(choice):
            state.add(choice)       # ఎంచుకో
            backtrack(state, ...)   # explore చేయి
            state.remove(choice)    # రద్దు చేయి
```

ఈ మూడు-దశల నమూనా - **ఎంచుకో, అన్వేషించు చేయి, రద్దు చేయి** - దాదాపు ప్రతి బ్యాక్‌ట్రాకింగ్ సమస్య యొక్క వెన్నెముక.

## Permutations

`[1, 2, 3]` యొక్క అన్ని వరుసక్రమాలు సృష్టించు చేయండి. ప్రతి స్థాయి లో, ఉపయోగించని సంఖ్య ఎంచుకోండి, రికర్స్ చేయండి, తర్వాత un-pick చేయండి.

```
         []
      /   |   \
    [1]  [2]  [3]
    / \   ...
 [1,2] [1,3]
   |      |
[1,2,3] [1,3,2]  ... (6 మొత్తం)
```

**n!** permutations ఉంటాయి, కాబట్టి సమయ సంక్లిష్టత O(n × n!).

## Combinations మరియు Subsets

**Combinations (n choose k):** ప్రతి ఎలిమెంట్ వద్ద, దాన్ని చేర్చండి లేదా దాటవేయండి చేయండి, duplicates నివారించడానికి ముందుకు మాత్రమే రికర్స్ చేయండి.

**Subsets:** size నియమం లేకుండా అదే ఆలోచన - రికర్షన్ ట్రీ లో ప్రతి నోడ్ valid ఉపసమితి. **2ⁿ** subsets ఉంటాయి.

<ThinkAboutIt>Permutations n! ఫలితాలు ఇస్తాయి, subsets 2ⁿ ఇస్తాయి. n=10 కి, అది 3,628,800 vs 1,024 - భారీ తేడా. ఎందుకు?</ThinkAboutIt>

## N-Queens - వివరణ

N×N బోర్డు పై N queens ను ఒకరినొకరు attack చేయకుండా ఉంచండి. N=4 కి:

```
. Q . .
. . . Q
Q . . .
. . Q .
```

**వ్యూహం:** ప్రతి వరుస కి ఒక రాణి ఉంచండి. ప్రతి వరుస కి ప్రతి కాలమ్ ప్రయత్నించండి. కాలమ్, main diagonal మరియు anti-diagonal conflicts తనిఖీ చేయండి. Safe అయితే ఉంచి తదుపరి వరుస కి రికర్స్ చేయండి. Stuck అయితే బ్యాక్‌ట్రాక్.

మూడు sets తో conflicts ట్రాక్ చేయండి: `cols`, `diag` (వరుస − కాలమ్) మరియు `anti_diag` (వరుస + కాలమ్).

## Sudoku Solver - భావన

ఖాళీ సెల్ కనుగొని, 1-9 అంకెలు ప్రయత్నించండి. ప్రతి digit కి వరుస, కాలమ్ మరియు 3×3 బాక్స్ నియమాలు తనిఖీ చేయండి. సరైనది అయితే ఉంచి రికర్స్ చేయండి. ఏ digit పనిచేయకపోతే, అన్‌డూ చేసి బ్యాక్‌ట్రాక్. నియమాలు నుండి ప్రూనింగ్ భారీ సెర్చ్ స్థలం ఉన్నప్పటికీ దీన్ని సాధ్యం చేస్తుంది.

## గ్రిడ్ లో పదం సెర్చ్

2D అక్షరాలు బోర్డు మరియు target పదం ఇచ్చినప్పుడు, ప్రతి సెల్ నుండి ప్రారంభించి నాలుగు దిశలలో DFS చేయండి, ఒక అక్షరం చొప్పున సరిపోలిక చేస్తూ. రికర్షన్ సమయంలో సెల్‌లు ను సందర్శించిన గా గుర్తు చేసి, **బ్యాక్‌ట్రాక్ చేసేటప్పుడు unmark** చేయండి.

## బ్యాక్‌ట్రాకింగ్ యొక్క సమయ సంక్లిష్టత

ఖర్చు **branching factor** (ప్రతి step లో ఎంపికలు) మరియు **లోతు** (solution కి దశలు) పై ఆధారపడుతుంది. b branches మరియు d లోతు కి: O(bᵈ).

| సమస్య | Branching | లోతు | Complexity |
|--------|-----------|-------|------------|
| Permutations | n, n−1, … | n | O(n!) |
| Subsets | 2 | n | O(2ⁿ) |
| N-Queens | ~n | n | O(n!) చెత్త పరిస్థితి |

## ప్రూనింగ్ ద్వారా Optimisation

**ప్రూనింగ్** అంటే విఫలమవుతాయని తెలిసిన branches ను దాటవేయండి చేయడం. ఉదాహరణలు:
- N-Queens: ఇప్పటికే occupied కాలమ్‌లు దాటవేయండి.
- Sudoku: నియమాలు ఉల్లంఘించే అంకెలు దాటవేయండి.
- Combination మొత్తం: remaining మొత్తం < 0 అయితే దాటవేయండి.

మంచి ప్రూనింగ్ అసాధ్యమైన సెర్చ్ ను వేగవంతమైనదిగా మార్చగలదు.
