## 什么是堆？

**堆**是一个完整的二叉树，其中每个父级都满足**堆属性** - 要么总是小于（最小堆），要么总是大于（最大堆）比其子级。 “完整”意味着每个级别都已满，除了最后一个级别，它从左到右填充。

```
       1            Min-heap
      / \
     3   5
    / \
   7   4
```

因为它是完整的，所以我们将其存储在**平面数组**中 - 不需要指针。对于索引 `i`：左子项 = `2i + 1`，右子项 = `2i + 2`，父项 = `(i - 1) // 2`。

## 最小堆与最大堆

|物业 |最小堆|最大堆 ​​|
|----------|----------|----------|
|根|最小元素 |最大元素 |
|父母≤孩子？ | ✅ 是的 | ❌ 否 (≥) |
|提取物给出 |最低 |最大|

默认情况下，Python 的 `heapq` 是一个 **最小堆**。对于最大堆，在插入时对值取反，并在提取时再次取反。

## 插入和提取 - 一步一步

**插入** - 推到末尾，然后**向上冒泡**（在较小时与父级交换）：

```python
import heapq
h = [1, 3, 5, 7]
heapq.heappush(h, 2)  # h becomes [1, 2, 5, 7, 3]
```

**提取最小值** - 与最后一个元素交换根，最后弹出，然后**向下筛选**（与较小的子元素交换）：

```python
smallest = heapq.heappop(h)  # returns 1
```

这两个操作的运行时间都是 O(log n)**，因为树的高度是 log n。

## Heapify - 在 O(n) 中构建堆

调用 `heapq.heapify(arr)` 将列表转换为堆 **就地**，时间复杂度为 O(n)，而不是 O(n log n)。它自下而上地工作，筛选每个非叶节点。这是计算机科学中最令人惊讶的复杂性结果之一。

<FunFact>构建堆的时间复杂度为 O(n)，而不是 O(n log n)。大多数节点都接近底部，几乎不需要向下筛选 - 数学计算为线性时间。</FunFact>

## 优先级队列抽象

**优先级队列**让您始终首先访问优先级最高的项目。堆是首选实现，因为插入和提取都是 O(log n)。当您需要“给我迄今为止最好的物品”时，请随时使用它。

## 模式：Top-K 问题

> “在未排序的数组中查找 K 个最大的元素。”

保留大小为 K** 的 **最小堆。对于每个元素，推它；如果堆超过 K，则弹出最小的。剩下的是K最大的。

```python
import heapq
def top_k(nums, k):
    return heapq.nlargest(k, nums)
```

时间：**O(n log k)** - 比 k <n 时的排序要好得多。

## 模式：合并 K 个排序列表

将每个列表的头推入最小堆。弹出最小的元素，然后推送同一列表中的下一个元素。重复直到所有列表都用完。时间：**O(N log K)**，其中 N 是元素总数。

## 模式：数据流中值

维护两个堆：下半部分的**最大堆**和上半部分的**最小堆**。平衡它们的大小，使它们最多相差 1。中位数始终位于一个或两个根处。

```
Lower half (max-heap): [1, 2, 3]  ← max = 3
Upper half (min-heap): [4, 5, 6]  ← min = 4
Median = (3 + 4) / 2 = 3.5
```

## 调度问题

堆在调度方面表现出色：会议室（跟踪最早结束时间）、带冷却时间的任务调度或 CPU 作业队列。关键的见解是堆有效地跟踪“接下来完成的内容”。

## 何时使用堆、排序数组、BST

|需要|最佳选择|为什么 |
|------|-------------|-----|
|重复最小/最大提取 |堆| O(log n) 插入 + 提取 |
|静态数据，一次性排序 |排序数组 | O(n log n) 一次，O(1) 访问 |
|范围查询+订单统计 |平衡 BST |一切皆为 O(log n) |
|来自流的 Top-K |大小为 K 的堆 |总共 O(n log k) |
