## रिकर्शन Fundamentals

Recursive फ़ंक्शन खुद को समस्या के **छोटे** संस्करण के साथ कॉल करता है जब तक **base स्थिति** न आ जाए जो चेन रोक दे।

हर रिकर्शन को दो चीज़ें चाहिए:
1. **बेस स्थिति** - सबसे सरल इनपुट जहाँ सीधे लौटाएँ करो।
2. **Recursive स्थिति** - समस्या तोड़ो और खुद को कॉल करो।

```python
def factorial(n):
    if n <= 1:        # base case
        return 1
    return n * factorial(n - 1)  # recursive case
```

## कॉल स्टैक - दृश्य रूप

हर रिकर्सिव कॉल कॉल स्टैक पर एक frame पुश करती है। बेस स्थिति लौटाएँ होने पर फ़्रेम उल्टा क्रम में पॉप होते हैं।

```
factorial(4)
  → factorial(3)
    → factorial(2)
      → factorial(1) → returns 1
    ← returns 2
  ← returns 6
← returns 24
```

बेस स्थिति न हो तो स्टैक ओवरफ़्लो। Python की डिफ़ॉल्ट रिकर्शन सीमा 1,000 फ़्रेम है।

<FunFact>Python की डिफ़ॉल्ट रिकर्शन सीमा 1,000 intentionally conservative है। sys.setrecursionlimit() से बढ़ा सकते हो, लेकिन गहरा रिकर्शन के लिए iterative समाधान बेहतर हैं।</FunFact>

## फ़िबोनाची - क्लासिक Trap

Naïve रिकर्सिव फ़िबोनाची O(2ⁿ) है क्योंकि एक-सा उप-समस्याएँ बार-बार गणना होते हैं। मेमोइज़ेशन इसे O(n) समय और जगह में fix करता है।

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)
```

## बैकट्रैकिंग - सब Try करो, फिर अनडू करो

बैकट्रैकिंग रिकर्शन है एक twist के साथ: **चयन बनाओ**, रिकर्स करो, फिर **चयन अनडू करो** और अगला option आज़माता है करो। सोचो जैसे भूलभुलैया समझते हैं कर रहे हो - आगे जाओ, dead अंत मिला, वापस आओ, दूसरा रास्ता आज़माता है करो।

### बैकट्रैकिंग Template

```python
def backtrack(state, choices):
    if is_solution(state):
        result.append(state.copy())
        return
    for choice in choices:
        if is_valid(choice):
            state.add(choice)       # choose
            backtrack(state, ...)   # explore
            state.remove(choice)    # un-choose
```

यह **चुनें, समझते हैं, un-चुनें** पैटर्न लगभग हर बैकट्रैकिंग समस्या की रीढ़ है।

## Permutations

`[1, 2, 3]` के सभी orderings बनाते करो। हर स्तर पर unused संख्या चुनें करो, रिकर्स करो, फिर un-pick करो।

```
         []
      /   |   \
    [1]  [2]  [3]
    / \   ...
 [1,2] [1,3]
   |      |
[1,2,3] [1,3,2]  ... (6 total)
```

**n!** permutations होते हैं, तो समय जटिलता O(n × n!) है।

## Combinations और Subsets

**Combinations (n चुनें k):** हर एलिमेंट पर include करो या छोड़ें करो, लेकिन duplicates से बचने के लिए सिर्फ forward रिकर्स करो।

**Subsets:** एक-सा विचार बिना आकार बाधा - रिकर्शन ट्री का हर node मान्य सबसेट है। **2ⁿ** सबसेट होते हैं।

<ThinkAboutIt>Permutations n! नतीजे देते हैं जबकि सबसेट 2ⁿ। n=10 के लिए 3,628,800 vs 1,024 - बहुत बड़ा अंतर। क्यों?</ThinkAboutIt>

## N-क्वीन्स - Walkthrough

N×N बोर्ड पर N क्वीन रखो जो एक-दूसरे को attack न करें। N=4 के लिए:

```
. Q . .
. . . Q
Q . . .
. . Q .
```

**Strategy:** हर पंक्ति में एक क्वीन रखो। हर पंक्ति के लिए हर कॉलम आज़माता है करो। Column, main डायगोनल, और एंटी-डायगोनल टकराव जाँच करो। Safe हो तो रखो और अगला पंक्ति पर रिकर्स करो। Stuck हो तो बैकट्रैक।

Conflicts ट्रैक करो तीन sets से: `cols`, `diag` (पंक्ति − कॉलम), `anti_diag` (पंक्ति + कॉलम)।

## सुडोकू Solver - अवधारणा

Empty सेल ढूँढो, अंक 1–9 आज़माता है करो। हर अंक के लिए पंक्ति, कॉलम, और 3×3 box बाधाएँ जाँच करो। Valid हो तो place करो और रिकर्स करो। कोई अंक काम न करे तो अनडू करो और बैकट्रैक। Constraints की प्रूनिंग huge खोज जगह को संभालने योग्य बनाती है।

## शब्द खोज in a ग्रिड

2D बोर्ड of अक्षर और लक्ष्य शब्द दिया है। हर सेल से शुरू करो और DFS से four directions में एक अक्षर मिलान करते जाओ। रिकर्शन में सेल देखे गए चिह्नित करो और **बैकट्रैक पर unmark** करो।

## बैकट्रैकिंग की समय Complexity

Cost **branching factor** (हर कदम पर choices) और **गहराई** (समाधान तक कदम) पर निर्भर करती है। b शाखाएँ, d गहराई: O(bᵈ)।

| समस्या | Branching | Depth | Complexity |
|---------|-----------|-------|------------|
| Permutations | n, n−1, … | n | O(n!) |
| Subsets | 2 | n | O(2ⁿ) |
| N-क्वीन्स | ~n | n | O(n!) सबसे खराब स्थिति |

## प्रूनिंग से Optimise करो

**प्रूनिंग** का मतलब ऐसी शाखाएँ छोड़ें करना जो असफल होंगी:
- N-क्वीन्स: पहले से occupied कॉलम छोड़ें करो।
- सुडोकू: बाधाएँ violate करने वाले अंक छोड़ें करो।
- Combination योग: बाकी योग < 0 हो तो छोड़ें।

अच्छी प्रूनिंग अव्यावहारिक खोज को तेज़ बना सकती है।
