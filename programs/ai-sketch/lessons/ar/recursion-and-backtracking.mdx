## أساسيات العودية

تستدعي الدالة العودية نفسها بنسخة **أصغر** من المشكلة حتى تصل إلى **الحالة الأساسية** التي توقف السلسلة.

كل تكرار يحتاج إلى شيئين:
1. **الحالة الأساسية** - أبسط إدخال يمكنك الرجوع إليه مباشرة.
2. **حالة متكررة** - قم بتقسيم المشكلة واتصل بنفسك.

```python
def factorial(n):
    if n <= 1:        # base case
        return 1
    return n * factorial(n - 1)  # recursive case
```

## مكدس الاستدعاءات - متصور

تقوم كل مكالمة متكررة بدفع الإطار إلى مكدس الاستدعاءات. عندما تعود الحالة الأساسية، تظهر الإطارات بترتيب عكسي.

```
factorial(4)
  → factorial(3)
    → factorial(2)
      → factorial(1) → returns 1
    ← returns 2
  ← returns 6
← returns 24
```

إذا لم يكن هناك حالة أساسية، فإن المكدس يفيض. الحد الأقصى للتكرار الافتراضي في Python هو 1000 إطار.

<FunFact>يعد حد التكرار الافتراضي لـ Python وهو 1000 متحفظًا عن قصد. يمكنك رفعها باستخدام sys.setrecursionlimit()، ولكن عادةً ما تُفضل الحلول التكرارية للتكرار العميق.</FunFact>

## فيبوناتشي - الفخ الكلاسيكي

فيبوناتشي العودي الساذج هو O(2ⁿ) لأنه يعيد حساب نفس المسائل الفرعية. يعمل التذكير على إصلاح هذا في الزمان والمكان O(n).

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)
```

## التراجع - جرب كل شيء، ثم تراجع عنه

التراجع هو تكرار مع تطور: أنت **تختار**، ثم تتكرر، ثم **تتراجع عن الاختيار** قبل تجربة الخيار التالي. فكر في الأمر على أنه استكشاف متاهة - قم بالسير للأمام، أو الوصول إلى طريق مسدود، أو الرجوع للخلف، أو تجربة المسار التالي.

### نموذج التراجع

```python
def backtrack(state, choices):
    if is_solution(state):
        result.append(state.copy())
        return
    for choice in choices:
        if is_valid(choice):
            state.add(choice)       # choose
            backtrack(state, ...)   # explore
            state.remove(choice)    # un-choose
```

هذا النمط المكون من ثلاث خطوات - ** اختر، واستكشف، وألغِ الاختيار ** - هو العمود الفقري لكل مشكلة تراجع تقريبًا.

##التباديل

إنشاء كافة أوامر `[1, 2, 3]`. في كل مستوى، اختر رقمًا غير مستخدم، ثم كرره، ثم قم بإلغاء الاختيار.

```
         []
      /   |   \
    [1]  [2]  [3]
    / \   ...
 [1,2] [1,3]
   |      |
[1,2,3] [1,3,2]  ... (6 total)
```

هناك **n!** التباديل، وبالتالي فإن التعقيد الزمني هو O(n × n!).

## المجموعات والمجموعات الفرعية

**المجموعات (n اختر k):** عند كل عنصر، قم بتضمينه أو تخطيه، ولكن قم بالتكرار للأمام فقط لتجنب التكرارات.

**المجموعات الفرعية:** نفس الفكرة بدون قيود على الحجم - كل عقدة في شجرة التكرار هي مجموعة فرعية صالحة. هناك **2ⁿ** مجموعات فرعية.

<ThinkAboutIt>التباديل تنتج ن! النتائج بينما تنتج المجموعات الفرعية 2ⁿ. بالنسبة إلى n=10، يكون هذا 3,628,800 مقابل 1,024 - وهو فرق هائل. لماذا؟</ThinkAboutIt>

## إن-كوينز - تجول

ضع ملكات N على لوحة N×N حتى لا يهاجم أي منهم الآخر. بالنسبة لـ N=4:

```
. Q . .
. . . Q
Q . . .
. . Q .
```

**الاستراتيجية:** ضع ملكة واحدة في كل صف. لكل صف، حاول كل عمود. التحقق من التعارضات بين الأعمدة والقطر الرئيسي والقطري المضاد. إذا كان آمنًا، ضعه ثم عد إلى الصف التالي. إذا عالقة، التراجع.

تتعارض التعارضات مع ثلاث مجموعات: `cols`، `diag` (صف - عمود)، و`anti_diag` (صف + عمود).

## سودوكو حلالا - المفهوم

ابحث عن خلية فارغة، جرب الأرقام من 1 إلى 9. لكل رقم، تحقق من قيود الصف والعمود والمربع 3 × 3. إذا كانت صالحة، ضع وكرر. إذا لم يعمل أي رقم، قم بالتراجع والتراجع. إن التقليم من القيود يجعلها قابلة للتتبع على الرغم من مساحة البحث الضخمة.

## البحث عن الكلمات في الشبكة

بالنظر إلى لوحة حروف ثنائية الأبعاد وكلمة مستهدفة، ابدأ من كل خلية وDFS في أربعة اتجاهات، ومطابقة حرف واحد في كل مرة. قم بتمييز الخلايا على أنها تمت زيارتها أثناء العودية و**قم بإلغاء تحديدها عند التراجع** للسماح بمسارات أخرى.

## التعقيد الزمني للتراجع

تعتمد التكلفة على **عامل التفرع** (الخيارات لكل خطوة) و**العمق** (خطوات الحل). بالنسبة للفروع b والعمق d: O(bᵈ).

| مشكلة | المتفرعة | العمق | التعقيد |
|---------|----------|-------|------------|
| التباديل | ن، ن−1، … | ن | يا(ن!) |
| مجموعات فرعية | 2 | ن | يا(٢ⁿ) |
| ن-كوينز | ~ ن | ن | يا (ن!) أسوأ الحالات |

## التقليم للتحسين

**التقليم** يعني تخطي الفروع التي تعلم أنها ستفشل. أمثلة:
- N-Queens: تخطي الأعمدة المشغولة بالفعل.
- سودوكو: تخطي الأرقام التي تنتهك القيود.
- المبلغ المختلط: تخطي إذا كان المبلغ المتبقي <0.

يمكن للتقليم الجيد أن يحول البحث غير العملي إلى بحث سريع.
